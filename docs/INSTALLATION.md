# 产物安装与节点版本

GitHub 从固定源码构建并签名正式发行产物。macserver 执行开发构建和预检；可信 GitHub 在实施与验收完成后独立重建、签名和发布。客户端安装、SSH 配对和 `scripts/onset.sh` 复用 `scripts/install-components.sh`，独立 `install.sh` 由同步脚本生成。

## 文件与所有者

```text
~/.local/bin/khor                                      共享的轻量启动脚本
<本机运行目录>/cli/<安装路径摘要>/<asset>/origin.json    安装归属
<本机运行目录>/cli/<安装路径摘要>/<asset>/current        本节点选择
<本机运行目录>/cli/<安装路径摘要>/<asset>/versions/      本节点不可变程序与占用租约
<本机运行目录>/cli/<安装路径摘要>/<asset>/update.json    安装收据
```

运行目录必须是受支持的本地文件系统。平台由 Linux/macOS 和 CPU 架构共同确定；同一 NFS HOME 上的启动脚本按实际执行机器选择自己的版本。更新 A 不改变 B 的选择，B 离线也不会被视作空闲。程序、数据身份、PID 和端口都按所属节点解释。

既有 `~/.local/bin/.khor/<asset>/current` 只作为尚未采用本地版本的节点的启动来源。节点首次采用时，将已验证的程序导入自己的运行目录；更新不改写这个共享来源，也不删除离线节点仍可能依赖的旧共享程序。

下载使用确切 tag、原始压缩字节大小和 SHA256，再用程序内置的公钥验证发行清单及资产签名。预放置包必须一并提供原始清单与签名。校验和不代替签名；源码身份、构建身份、目标平台和兼容契约不一致时拒绝启用。

`latest` 只选择正式版本；候选需明确指定 `KHOR_VERSION=vX.Y.Z-rc.N`。候选晋升保留原始二进制与 Apple build，用清单表达正式发布身份，不重新编译。

## 更新与会话

`khor upgrade --check` 检查版本，`khor upgrade` 更新本节点；`--channel beta` 选择候选通道，`--version vX.Y.Z` 选择明确版本。`khor upgrade --machine <已配对机器>` 在目标节点上执行，默认不更新其它机器。

安装先验证候选，再持有本节点的更新锁，原子切换本地指针并保存收据。候选、当前和一个回退版本复用既有运行镜像存储与内核占用租约。失败候选不挤掉回退版本；重复安装同一发行不把回退指针改成当前版本。进程退出后的遗留记录不会被当作活跃占用。

keeper 只采用已完成的选择；新启动的会话使用新版，旧会话宿主持有旧镜像直到自身退出。兼容性判断查看实际占用的旧契约，不以闲置缓存阻塞更新。当前 CLI 安装健康检查验证可执行身份和协议，完整服务启动失败回退仍须单独验收，不能将程序探测描述为服务健康证明。

共享 HOME 的 systemd 用户单元不保存安装机器的 PID。`Type=exec` 跟踪 keeper，`KillMode=process` 保留独立会话宿主；更新不会按进程名结束其它任务。

## SSH 与受限网络

目标先自行下载。只有明确的下载不可用状态 75 才触发控制端代下载；原压缩包、清单和签名通过独立临时目录传送，再交给同一原生安装入口重新验证。校验、权限、兼容和启动错误，以及 SSH 状态未知，都不会触发盲目替换。失败仅清理本次拥有的传输目录。

`onset.sh <ssh-host> [--release=tag] [--no-serve]` 使用这条路径；`--dry-run` 仅显示计划，不连接或编译。旧的 `--musl` 和 `--bin-on-target` 直接二进制部署入口已退役。`build-on.sh --no-install` 只产生开发构建，不能把未签名构建装入生产入口。

`onset --uninstall` 无法表达共享入口的所有消费者，遇到共享版本目录或受管启动脚本会在停止和删除前拒绝。按节点解除守护与删除整个共享安装是不同操作，不能通过删除共享入口代替。

## 验证边界

隔离 Shell/Python 检查覆盖目标先下载、三文件传输、错误不重试、临时目录清理、带空格和引号的路径及卸载归属。Rust 检查覆盖签名、传输边界、选择、回退收据和镜像占用。真实双构建 CLI Lab 验证初装、keeper、新旧任务、配对上传兜底与回收；其实际结果保存在本轮检查点中。

普通本地文件系统与同机双节点不代替真实 NFS、离线节点和手机操作验收。正式发布前还须核对实际目标平台的原生构建和真 App 行为。

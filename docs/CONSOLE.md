# khor 会话与命令

2026-10-23：khor 是用户与 Khor agent 的常驻主对话，同时保留显式命令和文件通道。
Pi 接入见 [AGENT.md](AGENT.md)，智能体协作基座见 [A2A.md](A2A.md)。

## 输入与执行

- 配置账户与模型后，普通文字提交给 khor agent；附件保留文件邀约通道。文字里的路径和命令不由输入框直接执行，网络动作通过工具与审批。
- `/命令 参数` 使用 khor CLI 的公开命令、别名和参数规则。没有 shell 展开，
  引号只用于组合参数；参数补全来自命令定义、设备、session 和实际目录。
- 后续 `@` 用来引用机器、agent 和工作 session；当前尚未实现引用解析。
  CLI 的 tell/send 现有参数语法保留在显式命令内部。
- 查询与普通操作直接调用共享执行器；需要持续终端的操作创建或打开 session。
  执行对象来自参数，未指定时是输入框连接的节点，命令卡显示执行节点。
- 需要标准输入的命令通过「附加输入」提交。不会读取 GUI 进程的标准输入。

## 一份能力，多个入口

`crates/commands` 拥有公开命令表、原有参数处理与执行函数。CLI 是薄入口，
slash 调用同一执行器。执行返回 stdout、stderr、直接生成的结构化数据、
session 引用及错误；不从终端输出反解析业务数据。

命令菜单只包含公开命令。内部进程入口仍由原生可执行文件接收，不对 slash
开放。Pi 使用明确的 MCP 目录调用网络业务能力，不自动暴露全部公开命令。

## 命令记录

会话身份保留 `wide/all`，显示名为 khor，单设备也可使用。

- 一次提交有固定 token；相同 token、相同输入返回同一记录，输入不同则拒绝。
- 执行节点先落盘认领，再开始操作。记录通过原有会话文档同步，接收记录不会执行。
- 操作结束更新原记录；长终端操作引用真实 session，由 session 提供工作状态。
- 重启发现原执行进程已退出时标记中断，不自动重放有副作用的操作。
- 凭据类命令的参数和结果不复制到全网历史；执行设备提供本地结果。

已读逐条确认活动页面实际显示的消息 id 和版本时间。同一毫秒到达的其他消息
不会被顺带清除；命令完成后，同一 id 的新版本仍需重新展示。后台、非活动标签、
阅读旧消息时不清新消息；返回底部后继续确认。

## 智能体与工作会话

普通文字直接交给 Khor agent，`@` 承担对象引用。智能体间的工作通过 A2A task
委派，具体执行 session 可以新建或复用；task、context 与 session 的身份和生命周期
分别记录，详见 [A2A.md](A2A.md)。

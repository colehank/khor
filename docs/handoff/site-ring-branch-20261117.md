## 本轮方向

上一版在一条新路径上做描边增长，导致中途是断裂的弧线；小标记又暂时没有四颗外珠，
机器、图标和标题各有一套到达节奏。新版本让几个结果都来自能看清的原图部件：

- 复制完整、闭合的玻璃外环及两条边缘高光，连续形变为 KhorNet 边界。
  不使用 stroke dash 描边增长，不重新出现一条替代的线。
- 图标核心保留外环、菱形、内环和中心珠，四颗外珠从核心移出，直接成为四台设备。
  回程核心没有预置外珠，由同一组机器节点归位后形成完整图标，不在中途复制或长出另一组节点。
- 图标较早开始收拢，外珠走短而直接的路径，取消单台服务器的额外绕行动线。
  珠面先转为设备底面，再显出设备字形；关系线在设备到位后出现。
- 外环副本收薄时，高光边缘的位置跟随实际带宽，防止形成两圈游离的细碎虚线。
- 标题缺口以几何缩放打开，到位后完整标题才用 120ms 淡入，不按字裁切。
  反向时先隐藏标题，再关闭缺口，避免文字与线条重叠。
- 光照的消退／恢复与玻璃材质退化／恢复使用同一段进度。
  收尾复用相同形变反向播放，关系线先退，四台设备回到外珠，外环与完整图标重新重合。

## 实现边界

仅改 `story-morph.ts`、`story-material.ts` 和 `narrative-tour.ts`。
不更改滚动距离、下载入口、自动可交互 GUI、40% 窗口底面或后续章节布局。
没有引入会话截图、案例段落、运行时动画库或真实网络连接。

`createStoryMaterial` 将四颗外珠及其局部光晕、阴影、高光和边缘从核心移入设备容器；
核心只保留中心珠，活动形变层始终是一个中心加四颗移动外珠。
`createStoryMorph` 从玻璃环的 gradient 克隆 paint server；路径始终闭合，厚度、材质和曲线独立连续改变。
外围高光以当前带宽确定位置，不以几何形变进度单独滞留。
网络标题只在缺口完全打开且标记到位后显现，原生网络／关系线在设备到位后展开。

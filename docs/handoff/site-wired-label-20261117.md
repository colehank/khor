# 有线网标题归属与曲线文字留白（2026-11-17）

用户反馈有线网标题画到了 Wi-Fi 超边。原因是两条边的上弧相交，标题锚点处于交叠区，虽然数据引用仍是 Wired，却读成了 Wi-Fi 的标签。

- 保持原有设备位置和所有闭合超边路径不变。宽屏 Wired 改放右上侧独立弧段；窄屏改放有线网下弧。
- `outline` / `ellipse` 支持可选 labelDirection。窄屏下弧反向绘制文字基线，保持文字正向，图标沿相同方向对齐。其他超边仍用默认方向。
- 标题和开口均从同一个固定参考姿态派生，手机漫游时不会漂移。
- 原来的整块文字 bbox 遮罩会以空白角落误擦相邻边（包括 KhorNet）。改为沿每个可见字符生成带相同留白的矩形，保留原本的沿弧开口与图标留白；掩膜几何只在重新排版/连接状态变化时更新，不在漫游逐帧重建。

验证：无头 Chrome，1440 英文深色、1024 中文浅色、390 中文深色、320 英文浅色。每个尺寸采样 Wi-Fi 内、移动中、蜂窝网内三个姿态，测量字形与 Wi-Fi/外圈/设备的距离，确认无交叠、标题位置固定。修改前字形与 Wi-Fi 距离为 0。另有定向 TypeScript、Astro 构建、git diff --check。

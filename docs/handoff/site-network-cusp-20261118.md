# Wi-Fi 漫游超边尖角修复（2026-11-18）

用户在 11 月 17 日截图圈出了 Wi-Fi 左侧变形时的尖角。旧实现把实时轮廓与标题参考轮廓按角度混合，局部出现很小的弯曲半径，固定角度间隔的三次曲线又会放大急弯。

## 实现

- Wi-Fi 用固定设备的平滑支撑函数，加上移动成员的有限影响 C2 smooth maximum。移动成员离开时影响连续收退，标题所在上弧自然不受它影响，无需再拼接参考曲线与实时曲线。
- 移动成员的退场偏移有界，外包络仍覆盖固定设备。
- `outline` 的可选自适应采样只为 Wi-Fi 启用：检查 1/4、1/2、3/4 处与解析曲线的位置误差、切线方向，必要时二分，最多 6 层。避免急弯区用一段长三次曲线插值造成回折。
- 坐标保留 6 位小数，避免细分控制点过早舍入。其余超边保持原有几何、节点位置、标题位置与方向；没有新增逐帧 DOM 测量或依赖。

## 验证

- 两种布局各检查 101 个漫游位置，采样实际 SVG 三次曲线导数。旧最小曲率半径约 3.82 / 10.17 图形单位，新约 34.02 / 30.96；控制段切线没有反向。自适应闭合边最多 83 / 76 段，未增加为全图高密度固定采样。
- Headless Chrome：桌面英文、手机中文，各观察 1、.75、.5、.25、0 五个姿态。标题与图标位置/路径固定，标题贴合对应边界；固定设备完整包在 Wi-Fi 内，完整加入时手机也在边界内。
- 回看有线网标题避让：1440 / 1024 / 390 / 320，三个漫游姿态，字形及留白没有碰到 Wi-Fi、KhorNet 或设备。

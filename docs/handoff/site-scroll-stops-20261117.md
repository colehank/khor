# 原生阅读停靠与滚动节奏（2026-11-17）

此吸附方案已于 2026-11-18 本地撤回：真实合成手势复现 proximity 也会将下一句拉回上一句。
现改为无吸附的原生滚动，完成态阅读距离保留。见 [回拉修复记录](site-scroll-recoil-20261118.md)。

用户授权实施已讨论的原生滚动方案；只修改本地，没有提交或发布。

## 变化

- 开场四次演化的总距离从 1.9 屏增至 3.8 屏，每次约 .84–1.03 屏。每段前 60% 变化、后 40% 保持完成态；起步仍直接响应滚动，没有延迟播放或时间锁。
- 初始阅读 .25 屏；Meet → Stay 用 .8 屏展开，随后 .4 屏保持；Agent 阅读 1 屏、合拢 .85 屏、Build 保持 .5 屏。
- 新增 `story-stops.ts`，在 sticky 容器之外的文档空间设置 9 个完成态停靠点（五句、网络、Continue、Agent、Build），补偿根元素导航 scroll-padding。不会把正在移动的图形当作目标。
- 根元素只在首页运行时启用原生 proximity + scroll-snap-stop:always。无 wheel/touch 拦截、无滚动纠正、无第三方滚动库；中间章节仍在普通文档流。
- 章节书签定位到 motionEnd 完成态，避免书签定位与吸附目标错位。
- visualViewport 放大时关闭吸附，恢复原倍率后重新启用；减少动态效果时关闭并隐藏停靠点；页面销毁清除标记、监听和根属性。

## 实验结论与范围

Chrome 中 mandatory 会使小幅手势回拉，重叠的大型吸附区域也不能作为可靠的自由阅读区，因此最终未保留强制吸附、模式切换或巨大区域方案。轻吸附配合更长的滚动距离用于减少误滑，不能宣称“一次手势绝不跨幕”；巨大单次指定 wheel 位移、滚动条拖动仍可跳过。

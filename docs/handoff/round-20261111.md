## 本轮行为

- 会话内打开文件和网址保留独立标签；关闭网页清理原生页面、停止媒体。HTML 使用完整网页预览，音视频支持播放和 Range 拖动。
- 新建会话显示不存在目录的提示，只在用户创建时新建；移动端工作区返回、终端前台恢复和机器导航保留统一结构。
- 附件使用可预览、逐项移除的卡片；终端面板在顶部发送，发送后返回键盘。浏览器本地文件夹支持逐层浏览和文件预览。
- 已读进度在节点间同步；同一 Shell 内启动和退出智能体保留原会话身份，不按同名合并独立会话。
- Khor 父行按“{N} 个子会话 ›”就地展开，子行使用普通会话的共享头像与类型。智能体与命令记录均进入普通只读标签，可切换、关闭和返回父页；不回复、不审批、不重新执行命令，关闭查看页不终止任务。
- 委派结束后保存终态并回收子会话，保留父 Khor 会话。只读查询绑定父运行和具体任务，旧任务仅展示实际留存的数据。
- 连接记录最新在前，版本 i 内展示当前机器的更新；导航菜单使用“设置”，非 Git 工作区隐藏 Git 历史。
- macOS 分 Apple 芯片和 Intel PKG；Windows 为 x64 MSI，Linux 为 x86_64/ARM64 DEB。App 随附同版本 CLI，桌面使用 `khor gui` 定位 App，保留已有独立 CLI 的安装归属。两种 Mac 的 App 更新使用 Tauri updater；Linux/Windows 桌面包由安装器或包管理器维护。
- 合入 main 的浅色、深色 App 图标；修复 Intel 运行镜像冷启动探测过早超时。

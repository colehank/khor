- CommitPage.tsx:84–91、154–166、196：选中路径暂存 ref；关闭生命周期消费并清空，先取消 Radix 默认归还焦点再将焦点交给目标（preventScroll）并定位。无选中项的 Escape 保留默认归还。section 可程序聚焦并有文件路径标签。回归明确要求 focusInTarget，稳定 body 不会假通过。

- use-chat-scroll.ts:72–93、99–110：输入窗口在实际惯性位移时延长，普通纯 scroll 在无 composer 保护时仍能更新阅读位置；仅实际 editable 最近焦点且 document 失焦时辅助保护 iframe 晚到滚动。pointermove 仅 buttons 非零续期；监听、observer 与 RAF 都有 cleanup。

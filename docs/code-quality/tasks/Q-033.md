## 生产设计与兼容边界

1. GUI Welcome保留 `{ok,why}` 形状，成功why为 `khor-gui/1`；不改 positional 字段、不冒充终端 HOST_VERSION。共用 `connect_welcomed` 只做原cookie/deadline握手，终端仍自行发原ClientOp::Version，GUI识别自身能力后不发额外协商帧。初连和已有far重连均更新能力。
2. 每个同步入场turn持独立 Sending 状态。Stop只有成功入controls队列后才同步标记此前已入场且未commit的turn，后入场turn不受旧取消影响。queued/uploading/committed分明；每帧writer内检查，Whole/Parts在writer内进入commit边界。committed input仍使用现有agent Stop，不谎称断线取消已提交prompt。
3. 新host Stop使当前connection的upload进入 discard-until-Parts；后续Part丢弃，Parts仅复位，普通控制继续处理。reader额外携带内部stopped-upload事实，host在没有活动prompt时回复既有 Turn(Cancelled)，而非错误NO_TURN。该事实不扩展wire enum。
4. 新client上传取消，turn worker等Stop真正写线后才发空terminator Parts，不继续发附件；同socket新turn必须等旧turn收尾。Stop完成由专门signal传达，队列被close/工作被丢弃也完成错误，避免cancelled turn永远等待一个不会执行的Stop。
5. 旧host缺能力时，仅在确认未commit upload才退役原attachment（left/gone、关闭两队列、独立shutdown原Connection），不自动向新连接补迟到Stop。原连接可得writer时仅做有界尽力Stop，安全性来自EOF使未commit upload丢弃。显式现有reload/重连入口恢复，GUI必须明确提示，不能伪装“对话已结束”。root已明确允许受限兼容，不要求扩展全局Connection代次/无感重连。真实chat_open重新连接后的下一turn、Mode/Option/权限能力仍待整链验证。

## 与 Q033-GUI 固定契约

`chatSay(id,text,images,files,token?)` 新增可选尾参，旧调用缺省/null兼容。token为非空、最多128字节、ASCII `[A-Za-z0-9._:-]`；拒绝错类型/超长/空token。仅core收据关联，不进入GuiOp/host/ACP wire；native与HTTP必须共同验证/透传。

`ChatFrame::SendCancelled { token: Option<String>, reconnect: bool }` 的TS kind为 `send_cancelled`。只保留小token，不在Frames长期保留原text/digest/附件。token=null的旧调用取消仍生效，但GUI无可靠草稿归属，不得盲目覆盖当前草稿。GUI为每次say/重试生成独立UUID，lastSay保留token及原line/full/images/docs，匹配取消才撤optimistic行/恢复内容；同文重发不同token。原files.clear会撤thumb，恢复附件不能复用已撤blob URL，此细节由GUI作者处理。

收据仅在确认输入未commit取消时产生，不重复推Unsent。reconnect=false表示保留连接可继续；true表示原attachment退役且需要显式重新连接，收据在gone=true前进入frames。chatStop的Ok继续表示本地Stop已写线/未发输入已取消/旧attachment已退役，不等于agent已完成取消；已commit输入仍等host Turn。chatSay取消以既有cancelled错误结束，GUI不解析字符串推断重连状态。

root 后续批准 `Unsent { miss, token: Option<String> }` 也统一原入场token。新增 SendJob 所有权guard：队列丢弃未执行工作、preceding-control错误与真正socket写错误都产生小收据，不依赖执行体才能走到finally。GUI不按current lastSay推断失败归属；promise reject可先于poll，snapshot保留至原token收据。已入场queued工作在attachment关闭时可能以既有attachment-closed错误结束，运行中的取消以cancelled结束；权威归属/重连信息都来自结构化frame，不解析错误文字。token=null只兼容展示，不覆盖新稿。

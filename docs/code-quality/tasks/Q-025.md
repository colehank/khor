## 新发现的生命周期约束

- host连接handshake结束后write_timeout设None（crates/node/host.rs:753/771）。Chat/Term conn被卡住时，现有leave没有shutdown；reader持Arc，移出registry并不自动关闭socket。
- 任何排队任务若在执行时按id重新查表，close/reopen同id后可能作用到新attachment；必须在同步入队处捕获Arc/代次，并在取消时拒绝旧任务，不能仅删全局队列key。
- term_open在registry持锁期间调用keep_history，可能写socket；需确保新主线程入口的“取得attachment”也不会间接等该网络锁。

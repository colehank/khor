## 已确认范围

沿用当前键行外观及“键行 … → 编辑键行”入口，新增“＋添加按键”。现有设置页入口复用同一编辑器。添加通过可视化选择完成，手机不必真实按出组合键。

编辑项包括：可选显示名称、Ctrl／Alt／Shift修饰键、基础按键、键帽预览及实际发送内容。名称留空时显示组合本身，例如⌃C或⇧Tab。保存后支持排序、隐藏、修改、删除；编辑草稿取消不应用。

首版支持两种定义：

| 类型 | 示例 | 点击行为 |
| --- | --- | --- |
| 组合键 | Ctrl+C、Ctrl+Shift+左方向键 | 发送一次组合按键 |
| 按键序列 | Ctrl+B → N | 按定义顺序依次发送，支持tmux前缀操作 |

默认添加组合键；“依次按键”作为额外选项展开序列编辑，不增加普通添加的负担。本项不扩展为脚本、任意命令宏或系统快捷键编辑器。

## 一致行为

- 自定义组合及序列每次点击执行一次，长按不连发；方向键等现有按键的连发保留。
- 自定义项按其定义发送，不意外叠加当前锁定的Ctrl／Alt。既有普通键与修饰键锁定行为保留。
- 实际点击键帽时保留终端焦点和软键盘，不因按钮取得焦点而收起键盘。
- 编辑器提供隔离试按区，只显示识别/编码结果，不发送到正在运行的终端。
- 配置默认按当前观看设备保存，在该设备的所有终端共用；重开后保留。远端机器不决定键行布局。
- 附件、更多入口、光标控制等既有键行布局保留。

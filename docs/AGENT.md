# Khor 智能体

网的调度员：用户指派任务，它动用网内的设备与 session 完成。
不是新形态——就是一个对话 kind 的 session：消息 CRDT 全网复制，
哪台设备都能留言；执行进程在 home（发起那台）。

## 权限：读免批，动作按档

看（设备状态、session 列表与内容、事件流）一律免批。
动作（开/杀 session、传文件、跑命令）分两档，按任务选，默认 manual：

| 档 | 规则 |
|---|---|
| manual（默认） | 先列计划，待批；批了计划内免批，计划外回来重批 |
| bypass | 全免批，用户显式选了才进这档 |

待批走 session 原语那一格。

## 执行

- home 是用户发起任务的那台。它离线：执行停在原地、灰显，消息照收（CRDT），
  等它回来——不悄悄换机器接着跑。
- 后果说破：从手机发起 = 手机是 home，锁屏即暂停（iOS 杀后台）。
  长任务从常开的机器发起；移交机制挂账以后。
- 用账户表里的账户（用户指定或默认），额度算在该账户头上。

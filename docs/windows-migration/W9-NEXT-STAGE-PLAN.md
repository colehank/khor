## 6. 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| 手机与 Windows 不同网段 | 网页面打不开 | 用 LAB 或 Tailscale（`100.72.59.72` 在线）验证 |
| 网页面只能看不能动 | Stage 1 要改成"修网页面" | T1-4 先定位，再决定 |
| Pi 账户不可用/无额度 | khor 对话仍不可用 | 用 Codex 作为 khor agent 后端（需要新的后端选择能力，另立项） |
| 常驻缺失 | 关掉 GUI 后无法遥控 | E2 决定是否开机自启 |

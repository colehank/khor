# PopupButton

应用内固定选项共用 Khor 选择菜单（2026-11-10，负责人要求统一字体并支持带内容的选项）。这取代旧版原生 `<select>` 约定；系统文件面板、系统菜单栏和右键菜单的职责不变。

- **plain**：设置行右端，透明底、悬停 `fill`，视觉高度 `ctl-md`；⌃⌄ 小片与开关右缘对齐。触控热区独立保留。
- **field**：占满表单一栏，`fill` 底与 `radius-sm`，右端同一枚 ⌃⌄。
- 当前值使用 `body` 与 `ink`；选项字体继承 Khor 的 `sans`。文字过长时按钮用 `short`，展开后显示完整 `label`。
- 选项的 `group` 显示组标题，`note` 显示补充内容，`preview` 绘制形状等内容；光标的块／竖线／下划线直接展示形状。禁用项不可选。
- 单选以勾显示当前项，选择后收起；多选使用复选项，选择后保持菜单，点外部或 Escape 关闭。
- 菜单共用现有 DropdownMenu / MenuViewport 的定位、安全边界和内部滚动，不再逐字段复制弹层。键盘打开定位当前可选项；方向键、Home/End、输入查找与 Escape 可用，关闭后焦点回到按钮。
- 选项多到需要搜索时，用现有搜索选择器；最多四个固定且值得全部展示的选择用 SegmentedControl。是／否用开关。
- 消费方负责值、选项和变更回调；自绘按钮不提供浏览器原生表单必填验证，表单提交必须验证必填选择。回答只留在当前任务，不写入对话或持久存储。

实现：`components/ui/popup-button.tsx`，设置行使用 `PopupRow`，智能体补问使用相同单选／多选控件。门：`npm run key-row-ui` 覆盖当前项、分组、禁用、类型查找、长列表边界、字体、多选和必填答案；完整 App Lab 验证实际设置中的光标选项与按键编辑。原生网页上方菜单与 iOS 实际键盘另做真机验收。

# PopupButton

从几个里选一个。`ctl-md` 28 高，`radius-sm` 6，底是透明的、悬停时 `fill`；右端那枚 `radius-xs` 4 的小片里是 ⌃⌄ 两个人字。按下去**打开系统的菜单**，不是自己画的下拉。

**两种样子，一个控件**（2026-09-28）：

- **plain**——设置行右端那一个：透明底、悬停 `fill`，和它的值一样宽。
- **field**——sheet 表单里的一行（新会话的「目标机器」、导入的两个筛选、注册账户的服务商）：`fill` 的底、`radius-sm`，占满那一栏，⌃⌄ 在右端。和分段控件的槽、搜索框是同一种底，一张 sheet 里的控件读起来是一家。

**什么时候用它，什么时候用分段控件**：选项会长（机器、目录、服务商、注册表）用它；≤ 4 个、不会长、值得全摆出来的，用 `SegmentedControl`。见那一页的表。

## 用

```jsx
<PopupButton value="跟随系统" />
<PopupButton look="field" label="目标机器" value="gate" choices={machines} />
```

桌面端真实实现是一个原生 `<select>`（`apps/gui/src/components/ui/popup-button.tsx`，`PopupRow` 也用它）：菜单的定位、键盘、滚动、长列表的行为全归平台，这是它比自绘下拉值钱的全部原因。消费方负责：当前值、选项、变化回调；一个选项的字太长时可以给按钮上另写一个短的（`short`，路径只显示最后一段，菜单里是全路径）。

一串带小标题的（智能体列出来的选项分组），每个选项写上 `group`，系统菜单里就是那一组的标题；一个选项要一句说明的（模式的描述），写 `note`——系统菜单没有第二行可放，它落在菜单项和按钮的提示上。按钮上画出来的当前值带 `data-popup-value`，门从那里读「它说自己设成了什么」（`<select>` 自己的字是所有选项的）。

**对话输入框上面那一行也是它**（2026-09-28）：「模式」和智能体列出来的每一个「选一个值」，此前是自己画的 Radix 下拉加单选项；是/否的那一项仍是开关。模式不是默认时，按钮上的字穿「等你」的墨，和标记一样。

## Do / Don't

- **有原生菜单的地方不要自己画浮层。** 这是整套系统里最容易被破坏的一条。
- 选项多到需要搜索时，它就不是弹出按钮了——改成导航行，进一个自己的页面。
- 当前值用 `body` 配 `ink`；**不要**把它降成 `secondary`，那是设置行里「附注」的位置。
- 两个选项时：是/否用开关；两个并列的值（计费 / 订阅、对话 / 终端）用分段控件。都不用弹出按钮。
- 在设置行里，**⌃⌄ 那枚小片的右缘落在行的右缘上**，和开关的槽、按钮对齐；按钮里 `pr-xxs` 那点内缩只在悬停的 `fill` 上看得到（2026-09-28）。

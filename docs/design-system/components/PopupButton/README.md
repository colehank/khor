# PopupButton

从几个里选一个。`ctl-md` 28 高，`radius-sm` 6，底是透明的、悬停时 `fill`；右端那枚 `radius-xs` 4 的小片里是 ⌃⌄ 两个人字。按下去**打开系统的菜单**，不是自己画的下拉。

## 用

```jsx
<PopupButton value="跟随系统" />
```

桌面端真实实现是一个原生 `<select>`：菜单的定位、键盘、滚动、长列表的行为全归平台，这是它比自绘下拉值钱的全部原因。消费方负责：当前值、选项、变化回调。

## Do / Don't

- **有原生菜单的地方不要自己画浮层。** 这是整套系统里最容易被破坏的一条。
- 选项多到需要搜索时，它就不是弹出按钮了——改成导航行，进一个自己的页面。
- 当前值用 `body` 配 `ink`；**不要**把它降成 `secondary`，那是设置行里「附注」的位置。
- 两个选项时用开关，不用弹出按钮。

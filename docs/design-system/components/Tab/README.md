# Tab

> **宽档的现状是 UX-39 §7（2026-10-06）**，见 `guidelines/10-layout.md`「宽档的标签」：胶囊横跨一行，未选中的平分、选中的从完整名字起长，每枚一直显示 ×，标签上没有动作（工作区条的 ↻ / ✓ 在胶囊后面），标签下不画日志线。下面「再按一下前面那枚」落下「一天」的那一段已经是来历：前面那枚现在开关会话的附栏，「一天」是附栏里「最近」的第一行。

> **2026-10-02 起是一张底加灰线**（README 颜色）：下面说的「纸」「框」「左块」都已是同一张底（`canvas` = `side` = `card`），分开元素的是 `hairline` 灰线、玻璃和选中行的灰块。这一段留作来历。

页型 B 的标签。`tab-w` 160 宽，被挤时到 `tab-w-min` 104 为止；上两角 `radius-md` 8，下面两角是方的——**选中的那枚是 `card`，和板接成一块**（板对应的那个角也跟着变方）。

**选中的标签和它下面的内容是一张纸**（2026-09-30，板是纸底是框）。标签条本身是框（`canvas`），未选中的标签透明地站在框上；选中的那枚是纸，板是纸，**终端也是纸**——以前终端画的是 `canvas`，负责人看到的正是「标签是板的灰，终端是底的黑」，两者不成一体（`check-palette`「终端的底 = 纸」量盒子、交给 xterm 的颜色、板、打开的标签四样一色）。脸的光晕和脸之间那道缝的颜色跟着脚下走：未选中的标签上是框的灰，选中的那枚上是纸（`app.css` `--halo-under`），否则纸色的缝落在灰框上会读成第二圈。

三个槽：16 的脸 · 名字 · `tab-close` 24 的关闭格。会话标签的脸是列表行那一套（光晕说状态、右下角标说类别，2026-09-02），**但按标签的尺寸画**：脸 16，光晕到 24，角标 `kind-mark-tab` 12 / 字形 10。整套墨——光晕和角标都算——必须在标签的盒子里；用行的 32 时光晕到 40，在 28 高的标签里顶出上沿 6（2026-09-28 列表审计第 6 条，`check-face`「列表四处错位」量）。窄档的会话页里它就是底栏上的标签本身（2026-10-02，下面「窄档：标签在脚下」），同一个尺寸。**类型标记跟着「…」→ 外观 →「类型标记」走**（2026-10-02）：默认浮现时标记画在 16 的脸正中，`kind-mark-tab` 12（四边各 2，整像素），墨按脸换、需要时压一层够用的罩（和行里同一份记录：标签的 12 正好是核心推墨时看的那一圈，脸中心直径 75%），没有角标；选角标时是上面那枚 12 / 10。12 而不是角标的 10：10 的时候终端那几笔不到一个像素，几何脸的色块从笔画里透出来。光晕两种画法一样。脸和名字之间是 `tab-gap` 12，不是 `gap-in` 8——负责人嫌 8「有些拥挤」（`check-face` 守着）。标签的高度和 L0 搜索框同高（负责人 2026-09-20「要和侧边栏搜索框的高度一致」），不单独取 34。

**签在中线上，脚接进板里**（2026-09-29，第一行收到 38）：一枚标签是 `ctl-md` 28 高的「签」（脸、名字、关闭格都在里面）落在第一行的中线上——和三颗窗口按钮、搜索框同一条线——下面是 `tab-lip` 5 的一截「脚」，把它接进板里；签上方离窗口上沿也是 5，那一条拖窗口。以前（48 那一行）标签站在行底，离上沿 20，就是负责人问的那块空白。脚也是标签的：打开它的那颗按钮伸进脚里，按在脚上照样是按标签，不是拖窗口。指针是手指时签是 `touch` 44、上下各 2，行 48。**关闭格永远不缩**，名字先截断。未选中的标签平时不显示关闭格，指过去才出现。

## 标签和行的关系

- 按一行 = 打开它的标签，或者切到已经开着的那一枚。
- **关标签不删行**；**删行关它的标签**。
- 列表的选中项**永远等于**最前面那个标签。

## 再按一下前面那枚（2026-09-29）

会话标签：**按已经在前面的那一枚，落下或收起这个会话的「一天」**（`components/DayStrip`），⏎ / Space 同理；按别的标签只是切换。它因此是一个 disclosure 按钮（`aria-expanded`，展开时 `aria-controls` 指着那一行）。双击名字仍是改名：按在名字上的单击等双击的窗口过去（300 ms）才生效，所以改名时带不会闪一下；按在脸上立刻生效。

指着前面那枚有一句提示，挂在标签下面：「点击查看近 24 小时状态」/「点击收起近 24 小时状态」，没有记录时「近 24 小时没有记录」（按了也不落）。这是 `Tooltip`「只给没有字的控件、只写一个名词」的明文例外，负责人点名要的。挂着这句提示的标签不再带系统 `title`（地址），免得一枚标签上叠两个浮层；未选中的标签照旧有 `title`，没有新提示。

标签条自己不知道落下的是什么：这是 `TabFace.again`（提示、是否展开、控制哪一行、按了做什么），只在前面那枚上读；「一天」是唯一的调用方。窄档的标签在会话页的底栏上，前面那枚同样是这个开关；那里提示挂在标签**上面**，「一天」浮在会话的**下沿**、紧挨着按它的那枚标签（`DetailPane`）。~~窄档没有标签条，详情屏头里的脸和名字是它的替身~~（2026-10-02 前）。

## 窄档：标签在脚下（2026-10-02）

负责人看了另一个手机终端：「我可能希望手机版的 session 布局大概是这样。上方完全交给内容，下方是操作与标签页」，并答：会话里不显示落地页的底栏、用「‹」回列表；标签放不下时**横着滚**，和宽档的标签条一样；对话也是同一个样子。窄档打开一个会话时，这一条标签就是会话页底栏的第一行（`components/SessionBar`）：

- **同一个 `TabStrip`**，`at="bottom"`：签、脚、宽度、压缩、滚动、计数都不变，只是**接口换了边**——内容在上面，所以选中的那枚从上面的纸**垂下来**：脚在上（`tab-lip`），下两角 `radius-md`，签照旧在这一行的中线上。行就是 `pane-head`（鼠标 38、手指 48），和顶上那条第一行同一个数。底栏和内容之间**没有线**：底的变化就是边，一条线会把选中的标签和它的会话切开。
- 行首是「‹」（钉在滚动区之前，`TabStrip` 的 `head`），行尾是计数（滚起来以后才有）、过期那一句，和手指下的键盘开关（`tail`）。打开的那样东西的动词还在标签上：再按前面那枚落下「一天」、双击名字改名、× 关掉这一枚；关掉最后一枚就回列表。
- 窄档原来那个一直在的计数按钮撤了：计数现在是宽档的规矩——标签条滚起来、不再把每一枚都摆出来时才出现，按下去是切换器那一屏。

## 用

```jsx
<Toolbar variant="tabs" trailing={<Button kind="plain" icon="plus" />}>
  <Tab active>khor</Tab>
  <Tab>hinton</Tab>
</Toolbar>
```

消费方负责：每一枚的名字和脸、哪一枚在前、关闭和新建的回调。

## Do / Don't

- **标签下面不许加副标题**。
- 标签上限是一个设置项；超过时先关最久没看的那一枚，并且在底部状态栏说一句。
- 窄档的会话页把标签条放在底栏，滚动而不折行；计数和宽档一样只在滚起来以后出现。~~窄档没有标签条，R0 右端换成一个标签计数按钮~~（2026-10-02 前）。

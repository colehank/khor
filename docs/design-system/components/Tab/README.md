# Tab

页型 B 的标签。`tab-w` 160 宽，被挤时到 `tab-w-min` 104 为止；上两角 `radius-md` 8，下面两角是方的——**选中的那枚是 `card`，和板接成一块**（板对应的那个角也跟着变方）。

三个槽：16 的脸 · 名字 · `tab-close` 24 的关闭格。会话标签的脸是列表行那一套（光晕说状态、右下角标说类别，2026-09-02），**但按标签的尺寸画**：脸 16，光晕到 24，角标 `kind-mark-tab` 12 / 字形 10。整套墨——光晕和角标都算——必须在标签的盒子里；用行的 32 时光晕到 40，在 28 高的标签里顶出上沿 6（2026-09-28 列表审计第 6 条，`check-face`「列表四处错位」量）。窄档详情头那张脸是标签的替身，同一个尺寸。脸和名字之间是 `tab-gap` 12，不是 `gap-in` 8——负责人嫌 8「有些拥挤」（`check-face` 守着）。标签的高度和 L0 搜索框同高（负责人 2026-09-20「要和侧边栏搜索框的高度一致」），不单独取 34。

**签在中线上，脚接进板里**（2026-09-29，第一行收到 38）：一枚标签是 `ctl-md` 28 高的「签」（脸、名字、关闭格都在里面）落在第一行的中线上——和三颗窗口按钮、搜索框同一条线——下面是 `tab-lip` 5 的一截「脚」，把它接进板里；签上方离窗口上沿也是 5，那一条拖窗口。以前（48 那一行）标签站在行底，离上沿 20，就是负责人问的那块空白。脚也是标签的：打开它的那颗按钮伸进脚里，按在脚上照样是按标签，不是拖窗口。指针是手指时签是 `touch` 44、上下各 2，行 48。**关闭格永远不缩**，名字先截断。未选中的标签平时不显示关闭格，指过去才出现。

## 标签和行的关系

- 按一行 = 打开它的标签，或者切到已经开着的那一枚。
- **关标签不删行**；**删行关它的标签**。
- 列表的选中项**永远等于**最前面那个标签。

## 再按一下前面那枚（2026-09-29）

会话标签：**按已经在前面的那一枚，落下或收起这个会话的「一天」**（`components/DayStrip`），⏎ / Space 同理；按别的标签只是切换。它因此是一个 disclosure 按钮（`aria-expanded`，展开时 `aria-controls` 指着那一行）。双击名字仍是改名：按在名字上的单击等双击的窗口过去（300 ms）才生效，所以改名时带不会闪一下；按在脸上立刻生效。

指着前面那枚有一句提示，挂在标签下面：「点击查看近 24 小时状态」/「点击收起近 24 小时状态」，没有记录时「近 24 小时没有记录」（按了也不落）。这是 `Tooltip`「只给没有字的控件、只写一个名词」的明文例外，负责人点名要的。挂着这句提示的标签不再带系统 `title`（地址），免得一枚标签上叠两个浮层；未选中的标签照旧有 `title`，没有新提示。

标签条自己不知道落下的是什么：这是 `TabFace.again`（提示、是否展开、控制哪一行、按了做什么），只在前面那枚上读；「一天」是唯一的调用方。窄档没有标签条，详情屏头里的脸和名字是它的替身（`DetailPane`）。

## 用

```jsx
<Toolbar variant="tabs" trailing={<Button kind="plain" icon="plus" />}>
  <Tab active>khor</Tab>
  <Tab>hinton</Tab>
</Toolbar>
```

消费方负责：每一枚的名字和脸、哪一枚在前、关闭和新建的回调。

## Do / Don't

- **标签下面不许加副标题**。
- 标签上限是一个设置项；超过时先关最久没看的那一枚，并且在底部状态栏说一句。
- 窄档没有标签条，R0 右端换成一个标签计数按钮。

# Menu

**这是给规格和预览用的复刻品。真正的 app 打开的是系统菜单。** 有原生菜单的地方不要自己画浮层——定位、键盘、滚动、长列表、无障碍，全归平台，这是它值钱的全部原因。

样子：`radius-lg` 10，底 `popover`，`float` 这一档阴影加 1 px `hairline`。项高由 `body` 决定，左侧留 22 给对勾，高亮项是 `brand-strong` + `on-brand`。

**行的右键菜单头两项永远是「置顶」「删除」**，然后一条分隔线，然后这一类东西自己的项。

## 用

```jsx
<Menu items={[
  { label: '置顶' },
  { label: '删除', destructive: true },
  { separator: true },
  { label: '在终端打开' },
]} />
```

## Do / Don't

- 菜单项是动词短语。会再问一次的带省略号。
- 删除是 `destructive` 的墨，**不是** `destructive` 的底。
- 菜单里不放开关、不放输入框、不放第二层以上的子菜单。
- 一行的动作**全部**在这里，不要在行里内嵌按钮（那会让行宽变成一个可以争的东西）。

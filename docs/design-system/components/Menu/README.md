# Menu

**这是给规格和预览用的复刻品。真正的 app 打开的是系统菜单。** 有原生菜单的地方不要自己画浮层——定位、键盘、滚动、长列表、无障碍，全归平台，这是它值钱的全部原因。

样子：`radius-lg` 10，底 `popover`，`float` 这一档阴影加 1 px `hairline`。项高由 `body` 决定，左侧留 22 给对勾，高亮项是 `brand-strong` + `on-brand`。

**行的右键菜单第一项永远是「置顶」，最后一项永远是「删除」**：中间是这一类东西自己的项；删除前面一条分隔线，自成一组。会毁东西的放最后（Apple HIG），不夹在两个撤得回的动作中间——手顺着菜单往下走，先经过的全是无害的。2026-09-28 列表审计第 16 条改的；此前是「头两项置顶、删除，然后分隔线」。`RowMenu` 按 `destructive` 把它挪到最后、画那条线，调用方列在哪儿都一样。

## 用

```jsx
<Menu items={[
  { label: '置顶' },
  { label: '在终端打开' },
  { separator: true },
  { label: '删除…', destructive: true },
]} />
```

## Do / Don't

- 菜单项是动词短语。会再问一次的带省略号：删除后面会弹确认窗时写「删除…」（`delete-ask`）；勾了「不再提醒」、按下去直接删的时候，同一项写回「删除」。字跟着真实会发生的事走，不跟着习惯走。
- 删除是 `destructive` 的墨，**不是** `destructive` 的底。
- 菜单里不放开关、不放输入框、不放第二层以上的子菜单。
- 一行的动作**全部**在这里，不要在行里内嵌按钮（那会让行宽变成一个可以争的东西）。

# OmniMenu：原生网页上方的候选列表

`OmniMenu` 只定义一份行结构、头像、匹配文字、选中玻璃、空状态和滚动容器。地址、机器和路径框负责候选与提交含义；原生适配器只负责把同一份列表放在网页上方。

## 分工

| 层 | 负责 | 不负责 |
|---|---|---|
| 字段与 `useFloatedMenu` | 焦点、中文组合输入、键盘、候选过滤、选中索引、取消、锚点及高度限制 | 平台 WebView 的叠层 |
| `OmniMenu` / 前端快照 | 行的实际样式、头像、文本、可滚区域及点击标识 | 机器选择和网页导航 |
| `menu_overlay.rs` | 当前 owner、lease、候选身份、过期回调拒绝 | 生成候选、解释地址 |
| Desktop / iOS 宿主 | 原生层级、坐标、尺寸、触摸转交、焦点与生命周期 | 第二份业务状态或第二套行样式 |

## 统一协议

- `show_menu({request: {id, at, rows, html?}})`：`id` 是本次展开的独立 lease；输入造成的候选更新沿用该 lease，关闭后再打开取得新 lease。`at` 为主界面 CSS 像素中的锚点，包含 `x/y/w/view/across/above`；底部药丸的候选向上展开。
- `menu_rows()` / `menu:rows` 交付 `{id, rows}`；冷启动由拉取补齐未接到的首个事件。
- `size_menu({id, h})` 只接受当前 lease 的有限正高度；行由实际布局量高，不在 Rust 重写字号和行高。
- `menu_pick({id, key})` 只接受当前 lease 中实际存在的候选；事件仅发回拥有该菜单的可信界面。
- `hide_menu({id})` 只允许该 owner 关闭其当前 lease；旧组件卸载、旧请求和旧测量不能关闭或唤回别人的列表。

owner 必须从实际 **WebView** 身份验证，不能只看父 Window 的名字：外部网页子视图与主界面可以属于同一 Window。外部站点没有菜单协议、Tauri 事件或应用操作权限。

## 平台能力

| 环境 | 浏览内容 | 候选宿主 |
|---|---|---|
| macOS | 独立原生网页 WebView | 预热、不可抢焦点的 Tauri 菜单窗口 |
| Windows | 独立 WebView2 | 相同桌面菜单适配器；缩放和系统装饰单独验收 |
| Linux | 独立 WebKitGTK | 相同桌面菜单适配器；窗口管理器的置顶与焦点行为单独验收 |
| iOS | 独立 WKWebView | 原生兄弟层中的可信菜单宿主；网页继续可见、保留句柄与滚动 |
| Android | 当前没有内嵌网页实现 | 普通前端字段仍使用 DOM 候选；不冒充已有原生浏览器或网页覆盖适配器 |
| Web 界面 | 不拥有独立原生网页层 | 原界面 DOM 候选 |

没有原生网页时，DOM 候选就是完整实现。原生宿主不可用时应明确回退和记录错误；不能默认把当前网页隐藏，继而声称完成了网页覆盖。对话框等其它浮层仍按其独立的任务容器规则处理。

## 原生边界

1. 字段始终保有输入焦点；候选可拖动滚动，按下后移出不提交，释放在行内才选择。外点关闭时不吞掉用户原本要点的网页操作。iOS 的只读候选 WK 子类同时拒绝 `canBecomeFirstResponder` 与 `becomeFirstResponder`，只改菜单实例；原生探针确认只拒绝前者仍会被 WebKit 的后者抢走焦点。DOM 阻止 `mousedown` 不能替代这道原生边界。
2. 菜单限制在可见视口与键盘之间，沿用 `MenuViewport` 的固定最大高度与内部滚动；不因候选出现改变底栏档位。旋转、软键盘、分屏、窗口移动与缩放重新定位。
3. 切标签、离开页面、应用退后台或 owner 消失后，候选不能残留或被迟到布局复活。恢复前台仅恢复仍有效的 owner/lease。
4. iOS 可信菜单使用独立、非持久 WK 配置；不复制主界面或外部网页的 user-content controller、Tauri IPC、代理、Cookie 或浏览器 shim。脚本桥只收带 lease 的候选点击和尺寸，验证消息来自菜单自身的主 frame。
5. 快照文本和头像按共享前端结构输出，拒绝外部网络资源与任意脚本；原生宿主不向外部网页暴露业务接口。跨 WebView 的 CSS blur 不等于能模糊下面的网页，真实材质必须在原生合成器验收。

## 验收

- `npm run native-menu`：直接按路径编译生产 Rust 协议模块的小型隔离测试，不链接 Tauri，不接触真实 home；覆盖 owner、过期关闭／测量／点击、候选身份与非法坐标。需要 Rust 和已有离线依赖，独立于默认前端测试；`KHOR_GATE_TMP` 可指向外置盘。
- `npm run native-menu-ui`：正式前端组件及快照的协议、样式、滚动、lease、关闭与监听清理；测试使用的原生 API 边界替身不代表实际原生层级。
- [iOS 原生手动夹具](../../../../apps/gui/scripts/native-menu-probe/README.md)：用符号链接编译当前生产适配器、导出正式候选快照并运行独立模拟器 App；保留已完成的 27 项原生检查，包括显式 first-responder 拒绝。构建与证据只写外部目录，不纳入默认门。
- 真 App：所有原生平台分别检查网页在列表下面仍可见且未重载；长短地址、无／少／很多机器、头像、当前项、深浅主题、系统字号、键盘与中文输入、滚动候选、点网页关闭、切标签和退后台；Desktop 另验多屏负坐标、缩放、拖窗口和不抢焦点，iOS 另验底栏半档／大档、网页手势与旋转。

发布记录须区分协议／前端通过、原生构建通过和实际设备验收，不以 Chrome 的截图替代 WKWebView/WebView2/WebKitGTK 的叠层结果。

# SearchField

L0 里那一个，`ctl-md` 28 高、`radius-sm` 6、底是 `fill`，左端放大镜，右端 `⌘K` 的 `caption` 提示。

**它是左块宽度的减压阀。** 列表被拖窄时，先压缩的是它：先藏 `⌘K` 提示，再让占位文字截断——在任何东西溢出之前。所以它不能有最小宽度，有了的话左块就不跟着缝走了，那正是「宽度有两个来源」这个 bug 的样子。

**它永远是一个框，不变成按钮**（2026-09-27，负责人：「搜索应该是个筐而非按钮」）。第十五轮起它窄到 256 以下会换成一颗放大镜按钮，那一条撤了：窄的时候是一个短框，框里只剩放大镜和光标。

## 用

```jsx
<SearchField placeholder="搜索会话" />
<SearchField placeholder="搜索设置" hint={null} />
```

消费方负责：占位文案（说清搜的是**这一个列表**）、输入值、⌘K 的处理。

## Do / Don't

- 打字过滤的是**当前这个列表**；⌘K 或 ⇥ 把它撑开成搜全部，结果垂在框下面，不加遮罩。
- 结果**不要**做成居中的命令面板。
- 占位文案写「搜索会话」「搜索设置」，不写「搜索」。

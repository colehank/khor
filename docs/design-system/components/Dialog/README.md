# Dialog

**按下去会问你事情的，一律是它**（2026-09-30 起，D10）：确认一件毁掉东西的事、填一张表新建一样东西、邀请一台设备。居中在窗口上，遮罩压暗后面，`radius-lg` 10，底 `popover`，`float` + `hairline`。暗色里 `popover` 比板（`card`）亮一档——影子在近黑的底上看不见，浮起来靠的是那块更亮的面（2026-09-28）。里面从上到下：`title-md` 17 的标题 · 内容（问句是一句话，`body` 配 `secondary`；表单是下面那张格子）· 可选的「不再提醒」· 右对齐的按钮。

**两种宽度，一种弹窗**：问一句话的 `dialog-w` 380；带表单的宽一档 32rem（`DialogContent form`）——两栏的表单在 380 里放不下「智能体」那一排分段——并且**按在外面不关**：打了一半的字不会被一次误点扔掉，Esc 和「取消」照关。别的都一样：同一个位置、同一块面、同一层遮罩。

**一个对话框里只有一个主按钮**：`primary`（`brand-strong`）或者 `destructive`，二选一，不能都有。取消在它左边，是普通按钮（`delete-keep`「取消」，每个对话框同一个词）。按钮用 `ctl-lg` 32。对话框没有角上的 ×：出路是「取消」和 Esc。

**对话框里的表单**（2026-09-28）：问题在左一栏、**右对齐**贴着答案，答案在右一栏——macOS 表单的习惯，一张表顺着一条边往下读，而不是一摞「标签压在控件上」。答案一律是系统形状的控件：会长的一串用弹出按钮（`field`），几个固定的用分段控件，要打字的是输入框；补一句说明的（密钥存在哪儿）写在答案那一栏里、控件下面。新会话、选择目录、登记账户站在这一张格子上（`components/ui/form-grid.tsx`，原来叫 `sheet-form`）；导入的两个筛选是并排的两个弹出按钮，不带标签（「所有机器」「所有目录」自己就说了）。只问一件事的（加入网络）不需要它。

**邀请设备**（2026-09-30，负责人：「邀请设备显示两个内容：现在的 token，和一个二维码，后者为手机连接奠定基础」）：一个邀请、两种写法——上面是二维码，下面是那串配对票（只读的框，点进去全选，能拷）和它还能用多久。**二维码里装的就是这串票本身**，同一个值，不另造网址：将来手机扫到的正是「加入网络」要的那串。码由节点编好、随票一起答回（`Ticket.qr`，`khor_gui_core::qr`：一条 SVG 路径，模块为单位，四个模块的静区已经写进坐标，`viewBox` 就是 `0 0 span span`），脸上画成 `<svg>`，墨是 `currentColor`（`ink`），底透明，`crispEdges`，15rem 见方；票太长编不成码时只有票。唯一的主按钮是「复制配对票」（当场做完，不带省略号，按下后说「已复制」/「无法复制」再回来），左边是「关闭」——票不因为关掉对话框作废，所以不是「取消」。暗色主题下码是浅墨在深底上（反色），iPhone 的相机认得；有的扫码器只认深在浅上，那时拷票。

## 用

```jsx
<Dialog
  title="删除 mandala？"
  message="这台机器上的会话记录会留在它自己那边，这里只是不再显示它。"
  confirm="删除"
  destructive
  remember
/>
```

消费方负责：标题、那一句话、按钮文案、两个回调、以及「不再提醒」的持久化。

## Do / Don't

- 标题是一个问句，点名**具体哪一个**（「删除 mandala？」不是「确认删除？」）。
- 那一句话说**会发生什么**和**什么不会发生**，不要重复标题。
- 按钮文案是动词（「删除」「全部关闭」），不是「确定」。
- **能重复做的事才给「不再提醒」**；一次性的不给。
- 新建和导入这类带表单的**也是对话框**，居中、压暗（`DialogContent form`）。⚠️ 墓碑：09-28 到 09-30 这里写的是「新建和导入这类带表单的不是对话框，是从 R0 落下的 sheet（D10）」——贴在 R0 下沿、不压暗、角上一个 ×；负责人读成「从标题下长出来的奇怪东西」，要的是「类似机器页点 ＋ 后的邀请设备弹窗」。sheet 变体整个删了，`data-sheet` 在整个 app 里为零（`check-face` 13 (b)）。
- 永远不要用 `alert()`。
- **编辑一样东西的窗是居中的对话框**（2026-09-30，机器的「编辑…」）：`title-md` 标题点名是哪一个（「编辑 peer」），里面是和 sheet 同一种表单格子（问题右对齐在左、答案在右）。**当场生效的选项（头像）选了就写，要打的字（名字）等「完成」**；所以唯一的主按钮是「完成」，旁边没有「取消」——没有能撤回的东西，Esc 关窗、不写名字。

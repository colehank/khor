# Dialog

确认一件毁掉东西的事。`dialog-w` 380 固定宽，`radius-lg` 10，底 `popover`，`float` + `hairline`。暗色里 `popover` 比板（`card`）亮一档——影子在近黑的底上看不见，浮起来靠的是那块更亮的面；从 R0 落下的 sheet 同样穿 `popover` + `float`，不穿板的 `card`（2026-09-28）。里面从上到下：`title-md` 17 的标题 · 一句话（`body` 配 `secondary`）· 可选的「不再提醒」· 右对齐的按钮。

**一个对话框里只有一个主按钮**：`primary`（`brand-strong`）或者 `destructive`，二选一，不能都有。取消在它左边，是普通按钮。按钮用 `ctl-lg` 32。

**sheet 里的表单**（2026-09-28）：问题在左一栏、**右对齐**贴着答案，答案在右一栏——macOS 表单的习惯，一张 sheet 顺着一条边往下读，而不是一摞「标签压在控件上」。答案一律是系统形状的控件：会长的一串用弹出按钮（`field`），几个固定的用分段控件，要打字的是输入框；补一句说明的（密钥存在哪儿）写在答案那一栏里、控件下面。新会话、选择目录、注册账户站在这一张格子上（`components/ui/sheet-form.tsx`）；导入的两个筛选是并排的两个弹出按钮，不带标签（「所有机器」「所有目录」自己就说了）。只问一件事的 sheet（用邀请加入）不需要它。

## 用

```jsx
<Dialog
  title="删除 mandala？"
  message="这台机器上的会话记录会留在它自己那边，这里只是不再显示它。"
  confirm="删除"
  destructive
  remember
/>
```

消费方负责：标题、那一句话、按钮文案、两个回调、以及「不再提醒」的持久化。

## Do / Don't

- 标题是一个问句，点名**具体哪一个**（「删除 mandala？」不是「确认删除？」）。
- 那一句话说**会发生什么**和**什么不会发生**，不要重复标题。
- 按钮文案是动词（「删除」「全部关闭」），不是「确定」。
- **能重复做的事才给「不再提醒」**；一次性的不给。
- 新建和导入这类带表单的**不是对话框**，是从 R0 落下的 sheet（D10）。
- 永远不要用 `alert()`。

# Dialog

**按下去会问你事情的，一律是它**（2026-09-30 起，D10）：确认一件毁掉东西的事、填一张表新建一样东西、邀请一台设备。居中在窗口上，遮罩压暗后面，`radius-lg` 10，底 `popover`，`float` + `hairline`。暗色里 `popover` 比板（`card`）亮一档——影子在近黑的底上看不见，浮起来靠的是那块更亮的面（2026-09-28）。里面从上到下：`title-md` 17 的标题 · 内容（问句是一句话，`body` 配 `secondary`；表单是下面那张格子）· 可选的「不再提醒」· 右对齐的按钮。

**手机上带表单的是一张从脚下升起的纸**（2026-10-07，UX-44 §1，负责人：「整个app的底栏风格一致，底栏颜色、布局等向点击药丸弹出的底栏一致」）：窄档的 `DialogContent form` 和会话的附栏是同一张纸——app 自己的底（不是 `popover`）、上沿一条灰线、`--menu-r` 的上两角、抓手在纸里面，写在 `app.css` 一处。**遮罩只有一层**（UX-44 §2）：`--sheet-scrim`，每个对话框、每个面板都是它——两个主题都是黑 0.5，都压暗（UX-49 §1，2026-10-08：暗色压在黑终端上正好是终端重连时整块内容半透明的样子）。~~`bg-black/50`~~。⚠️ 墓碑（UX-44 → UX-49）：暗色米白 0.16，往上提亮，黑终端读成灰。

**两种宽度，一种弹窗**：问一句话的 `dialog-w` 380；带表单的宽一档 32rem（`DialogContent form`）——两栏的表单在 380 里放不下「智能体」那一排分段——并且**按在外面不关**：打了一半的字不会被一次误点扔掉，Esc 和「取消」照关。别的都一样：同一个位置、同一块面、同一层遮罩。

**一个对话框里只有一个主按钮**：`primary`（`brand-strong`）或者 `destructive`，二选一，不能都有。取消在它左边，是普通按钮（`delete-keep`「取消」，每个对话框同一个词）。按钮用 `ctl-lg` 32。对话框没有角上的 ×：出路是「取消」和 Esc。

**对话框里的表单**（2026-09-28）：问题在左一栏、**右对齐**贴着答案，答案在右一栏——macOS 表单的习惯，一张表顺着一条边往下读，而不是一摞「标签压在控件上」。答案一律是系统形状的控件：会长的一串用弹出按钮（`field`），几个固定的用分段控件，要打字的是输入框；补一句说明的（密钥存在哪儿）写在答案那一栏里、控件下面。选择目录、登记账户站在这一张格子上（`components/ui/form-grid.tsx`，原来叫 `sheet-form`；新会话也是这张格子，但它站在新标签页的页面上，不在对话框里，UX-45）；导入不是表单格子，是一次搜索（2026-10-09，IMPORT-BRIEF）：上面一个搜索框、一排机器标签、点一行就导入并打开，页脚只有「取消」。⚠️ 墓碑：并排的两个弹出按钮「所有机器」「所有目录」。只问一件事的（加入网络）不需要它。

**邀请设备**（2026-09-30，负责人：「邀请设备显示两个内容：现在的 token，和一个二维码，后者为手机连接奠定基础」）：一个邀请、两种写法——上面是二维码，下面是那串配对票（只读的框，点进去全选，能拷）和它还能用多久。**二维码里装的就是这串票本身**，同一个值，不另造网址：将来手机扫到的正是「加入网络」要的那串。码由节点编好、随票一起答回（`Ticket.qr`，`khor_gui_core::qr`：一条 SVG 路径，模块为单位，四个模块的静区已经写进坐标，`viewBox` 就是 `0 0 span span`），脸上画成 `<svg>`，墨是 `currentColor`（`ink`），底透明，`crispEdges`，15rem 见方；票太长编不成码时只有票。唯一的主按钮是「复制配对票」（当场做完，不带省略号，按下后说「已复制」/「无法复制」再回来），左边是「关闭」——票不因为关掉对话框作废，所以不是「取消」。暗色主题下码是浅墨在深底上（反色），iPhone 的相机认得；有的扫码器只认深在浅上，那时拷票。

## 弹层的职责与边界（2026-10-18）

先按任务选容器，再适配屏幕；不是点了按钮就弹一个同样大的窗口。

| 任务 | 桌面 | 手机 |
| --- | --- | --- |
| 删除确认、放弃草稿、重置、输入短 PIN | 居中短对话框 | 居中短对话框；只承载这一个决定 |
| 重命名、编辑机器、登记／编辑账户、添加启动方式 | 表单对话框 | 从底部出现的任务弹层，内容适配高度；复杂编辑可以用较大的可见空间 |
| 导入会话、管理启动方式、选择目录、符号／历史／标签列表、附件预览 | 有边界的任务对话框 | 底部任务弹层；导入最多约可见区域七成，默认不抢键盘 |
| 机器／启动方式选择、路径推荐、工作区／浏览器切换 | 就近菜单／候选列表 | 同一种就近菜单／候选列表，不能再把外面的底栏拉起来 |
| 会话里的文件、工作区、网页 | 侧区 | 原有可调高度的会话内容底栏；它是持续浏览空间，不套一层表单弹窗 |
| 某一项的动作集合 | 右键／就近菜单 | 就近菜单或现有动作面板；需要额外确认的动作再问一次 |

`DialogContent form` 是表单／选择任务的现有入口；短确认和 PIN 不带 `form`。新会话仍是标签页内的页面，不能为一致而改回弹窗。账户编辑补齐 `form`，与登记、机器编辑一致。

**高度有一个公共上限**：所有对话框以 `visualViewport` 的可见高度和偏移为边界，软键盘、低矮桌面窗口和安全区都算进去。短内容自然收高；长内容必须能滚动到最后一项，不能靠增大窗口解决。普通内容有整个对话框滚动的兜底；长列表／长编辑用 `DialogContent scrollable` + `DialogBody`，标题和操作在滚动区外，不能叠到彼此上面。候选菜单自己保持 `MenuViewport` 的高度边界和边框，弹窗里的路径推荐参与布局，不能被外层滚动边界裁掉；候选高度还要受弹窗内容区的可见空间约束，不能只按整个窗口算。导入在搜索／过滤期间保持开始搜索时的高度，不能随着每个字上下跳。

**一张任务弹层只保留一个主滚动区**：启动方式列表和智能体目录分两步显示，「返回」回到管理列表；不能把两个最大高度列表往同一个窗口里叠。终端 DIY 配色的预览、色值和扩展色放在一个内容滚动区，取消／保存可达。

**手势先分归属**：`sheetGestureReserved` 统一保护菜单、listbox、路径候选、`MenuViewport`、滑条和 `data-sheet-hold`。一旦从这些区域开始，整个手势都归该区域，滚到顶／底也不改变外层高度。主文档仍沿用原有手势交接；抓手／药丸仍可拖底栏。推荐列表失焦收起不能让按钮在按下到点击之间移位，取消等动作一次点击完成。

门：`npm run dialogs`；`npm run dialogs -- --serve` 提供同一套正式组件和一次性数据，供 CUA／真机手动验收。触摸探针检查真实生产监听器的事件归属，不冒充 iOS 原生惯性、WKWebView 键盘动画或网页原生滚动的实测。

### 本轮覆盖盘点

- 公共边界覆盖所有 `DialogContent`：机器添加／编辑、目录选择、账户登记／编辑、网络／安全、邀请码、重命名、附件、键行编辑、列表、确认等。
- 显式单滚动区：启动方式管理／编辑、智能体目录、会话导入、目录选择、机器编辑、终端配色编辑。
- 共用菜单避让：表单弹层、会话内容底栏、旧 `SessionPlaceSheet`；`MenuViewport` 本身也声明保留手势。
- 保留原生差异：iOS 文件选择／预览、系统菜单和 macOS／Windows 窗口装饰由系统提供，不能为了外观相同重造。

## 用

```jsx
<Dialog
  title="删除 mandala？"
  message="这台机器上的会话记录会留在它自己那边，这里只是不再显示它。"
  confirm="删除"
  destructive
  remember
/>
```

消费方负责：标题、那一句话、按钮文案、两个回调、以及「不再提醒」的持久化。

## Do / Don't

- 标题是一个问句，点名**具体哪一个**（「删除 mandala？」不是「确认删除？」）。
- 那一句话说**会发生什么**和**什么不会发生**，不要重复标题。
- 按钮文案是动词（「删除」「全部关闭」），不是「确定」。
- **能重复做的事才给「不再提醒」**；一次性的不给。
- 导入这类带表单的**也是对话框**，居中、压暗（`DialogContent form`）。⚠️ 墓碑（UX-45，2026-10-07）：新建会话原来也是这里的一个——它现在是新标签页的页面（`views/NewSessionPage.tsx`，`components/Tab`「新标签页」），页面上的「创建」照旧是品牌色的主按钮——主按钮离开对话框的唯一一处（2026-10-07，负责人定）。⚠️ 墓碑：09-28 到 09-30 这里写的是「新建和导入这类带表单的不是对话框，是从 R0 落下的 sheet（D10）」——贴在 R0 下沿、不压暗、角上一个 ×；负责人读成「从标题下长出来的奇怪东西」，要的是「类似机器页点 ＋ 后的邀请设备弹窗」。sheet 变体整个删了，`data-sheet` 在整个 app 里为零（`check-face` 13 (b)）。
- 永远不要用 `alert()`。
- **编辑一样东西的窗是居中的对话框**（2026-09-30，机器的「编辑…」）：`title-md` 标题点名是哪一个（「编辑 peer」），里面是和 sheet 同一种表单格子（问题右对齐在左、答案在右）。**当场生效的选项（头像）选了就写，要打的字（名字）等「完成」**；所以唯一的主按钮是「完成」，旁边没有「取消」——没有能撤回的东西，Esc 关窗、不写名字。

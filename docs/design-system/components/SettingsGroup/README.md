# SettingsGroup

设置页（更多）里的一组。**它落在 `canvas` 上，不落在板上**：设置式的「…」页不画板（`Board` 的例外），因为一张 `card` 的组放在 `card` 的板上就没了。组名在卡片**外面、上面**，用 `group` 11/600 配 `tertiary`；卡片是 `card` 的底、`radius-lg` 10 的角；行与行之间是 `hairline`，**左端内缩 `gap-row` 12**（和 macOS 一样，分隔线从文字开始，不从卡片边缘开始）。组与组之间 `gap-group` 20。

## 四种行，用途是排他的

| 行 | 右端 | 什么时候用 |
|---|---|---|
| **switch** | 开关 | 一件立刻生效、只有两种状态的事 |
| **popup** | `当前值 ⌃⌄`，打开**系统菜单** | 从几个里选一个 |
| **nav** | `值 ›` | 它自己有一页——在同一块板里打开子页，返回在 R0 |
| **action** | 按钮 | 做一次就完的动作 |

只陈述一件事、不给控件的行（版本、id、路径）是 **fact**：标题在左，值在右，`body` 配 `secondary`。action 行也可以在按钮左边带一个值（「store 在哪儿　/路径　打开这个目录」是一行），就像 popup 行在 ⌃⌄ 左边带当前值。

**一行的设置行不论哪一种都一样高**：一个控件（`ctl-md` 28）加上下各一个 `gap-in`，即 44；只有 `note` 让一行长高（2026-09-28，之前开关行和 fact 行 34、「khor 的界面」24、带按钮的 44，一组里三种高）。标题 `body` 配 `ink`，`note` `callout` 配 `secondary`。

**一条右缘。** 每一种行画出来的控件——开关的槽、⌃⌄ 那枚小片、按钮、fact 的值——右缘都落在同一条线上，离卡片右边 `gap-row`。热区可以比控件大，只往左长，不越过这条线（开关以前把热区往右拉了 8，所有开关都比按钮突出一截）。

**依附于开关的行，开关关着时不可用。** 像 macOS 那样：还在，变灰（标题、值、控件都到按钮禁用的 0.4），按不动。开关打开要先有前提时（锁要先有 PIN），前提由开关自己去要，不要让人去点一个灰着的行。`check-face` 4I 量这四条。

## 用

```jsx
<SettingsGroup label="标签页" rows={[
  { kind: 'popup',  title: '标签上限', note: '超过时先关最久没看的那一枚', value: '不限' },
  { kind: 'switch', title: '删除前确认', on: true },
  { kind: 'nav',    title: '已关闭的标签', value: '12 个' },
  { kind: 'action', title: '网站图标缓存', action: '清除…' },
]} />
```

消费方负责：每一行的值和回调。

## Do / Don't

- `note` 写**会发生什么**（「超过时先关最久没看的那一枚」），不写这个设置是什么。
- 一组里**不要**超过六行。超了就说明里面有两件事，拆成两组，各给一个组名。
- 组名**不要**复述页名：「通用」页的第一组不叫「通用」。页头已经说了，再说一遍是第二个标题；`MoreSection` 会把和页名相同的组名拿掉。
- 行名已经说了的，值里**不要**再说一遍：「PIN」那一行的值是「已设置」，不是「PIN 设过了」。
- 一个东西的动作放在它自己那一行的右端，**不要**另起一行、左对齐地摆一颗按钮。不属于任何一行的动作（安全页的「立即锁定」）是这一页的按钮，放 R0 右端（`Toolbar`），不放进组里。
- **不要**在组里放「保存」。每一行自己立刻生效。
- 危险的动作（清除、重置）用 `action` 行 + 一个带省略号的按钮，真正的确认在对话框里。

# DayStrip

`day-strip` 4 px 高的一条，在标签条下面、板的最上沿。一段一个颜色，用六个状态色里的那一个。**每一段是一颗胶囊**（`radius-full`），段与段之间 2 px 空——「除了分隔线，没有直角」，它曾是唯一的例外，2026-09-29 负责人要它和全 app 一致（「session的状态条也弄成圆角的bar」）。

**它是 R0 和 R1 之间唯一允许存在的东西**，而且它没有文字——这是它被允许存在的原因。想加一行字说明「今天干了什么」，那一行就得进板里。

没被看过的那几段用 `day-unwatched`，形状和词一样，只是墨；那时没有这个会话的几段什么都不画。

## 几何

- 带本身 4 px，坐在自己的一行里：上下各 `gap-xxs`（一行 12），左右离板边 `gap-in`——板的上角是 12 的圆，贴边的第一段和最后一段会被切成弧。
- **这一行就是它的热区，也只有这一行。** 每一段的热区上下各伸出 `gap-xxs`，正好填满这一行，不越出去：标签条的下沿是标签的，下面的内容是内容的（2026-09-29 之前热区往上伸 12、伸进标签条后面，只是被板的 `overflow: hidden` 连点击一起裁掉了，实际的靶子就是那 4 px）。
- **最短的一段也是一颗点（4 × 4）加它的 2 px 空。** 不在界面里合并短段：界面向节点要的格子至少 6 px 宽，合并交给节点自己那一套（`khor_core::DayCell::rank`，偏向「待批」）。代价是分辨率：900 宽的板上一格约 10 分钟，手机上约 23 分钟。

## 指、按、键

一段话，三条路，说的是同一件事：

- **指着**：立刻出现一个提示（`Tooltip` 的样子），挂在带的**下面**、夹在板里，写这一段的起止、词和时长——`10:05–11:55 · 待批 · 1 小时 50 分钟`。只写这一段，不写光标下那一分钟（那是一根时间轴，而这条带不画时间轴；手指也拿不到它）。
- **按 / 点**：一个浮层（`popover` + `float` + `radius-lg`，一种浮层语言），挂在这一段下面：带点的词、起止、时长；「未查看」多一句它是什么意思。手机没有悬停，这是它的路。点外面、按 Esc、再点同一段都会收起。浮层开着时提示不出现，一次只浮一样。**不放 24 小时合计**：格子是按「最想叫你的那个词」合并的，加出来的「待批 2 小时」可能是十二格里各一分钟。
- **键盘**：整条是一个 Tab 停点（`toolbar`），← → Home End 在段之间走，焦点环是 `ring`，提示跟着焦点走；⏎ / Space 打开浮层，Esc 收起、焦点回到那一段。

字全是目录的（六个词、`day-unwatched`、`day-unwatched-why`、时长的 `age-*`），` · ` 和 `–` 是标点。浮层里的字不能选：是读数，不是要抄走的值。控件上是箭头。

## 用

```jsx
<DayStrip spans={[{ width: '18%', word: 'busy' }, { width: '6%', word: 'done' }]} />
```

消费方负责：分段的宽度百分比和每一段的状态词。

## Do / Don't

- 状态色在这里是**填充**，这是六个词唯一被允许当填充用的地方——因为它是一条 4 px 的条，不是一块底，上面永远没有字。
- 不加刻度、不加时间轴、不加提示和浮层以外的任何东西。
- 别把它挪到板里面去。
- 别在界面里合并、排序或挑词：画什么是节点说的。
- 门：`npm run day` ⑥（胶囊与空、提示与浮层说同一段、手指点得开、一个 Tab 停点、热区不越出自己那一行）。

# DayStrip

> **现状（UX-39 §4，2026-10-06）**：这一条只在会话附栏的「最近」第一行「过去24小时」里画，上面一行是忙碌 · 空闲两个总数（`views/DayToday`）；按一段、指着一段说那一段的时间、状态和长度，这一行本身不展开。标签下、药丸下都不再有它或它压扁的日志线（⚠️ 墓碑 UX-36 的 `DayLine` / `DayPanel`、UX-30 §5 的标尺）。下面是来历。

`day-strip` 4 px 高的一条，在标签条下面、板的最上沿。一段一个颜色，用六个状态色里的那一个。**每一段是一颗胶囊**（`radius-full`），段与段之间 2 px 空——「除了分隔线，没有直角」，它曾是唯一的例外，2026-09-29 负责人要它和全 app 一致（「session的状态条也弄成圆角的bar」）。

**它是 R0 和 R1 之间唯一允许存在的东西**，而且它没有文字——这是它被允许存在的原因。想加一行字说明「今天干了什么」，那一行就得进板里。

没被看过的那几段用 `day-unwatched`，形状和词一样，只是墨；那时没有这个会话的几段什么都不画。

## 默认不画，按前面那枚标签才落下（2026-09-29）

负责人：「把这个状态bar设置为，点击标签后显示吧。悬停的时候加一个提示，点击查看近24小时状态。」

- **默认收着**：标签条下面没有这一行，也不给它留位置——会话从板的上沿直接开始。同一天早上负责人报的那条「标签下的空带」就是它：以前没有数据时它照样占着 12 px 的空行，加载时占，没有记录的会话永远占。
- **开关是最前面那枚标签**：再按一下已经在前面的标签，落下来；再按一下，收起。按别的标签只是切过去，和以前一样。⏎ / Space 按在有焦点的前标签上也一样。标签是一个 disclosure 按钮：`aria-expanded`，展开时 `aria-controls` 指着这一行（`khor-session-day`）。标签条不是 ARIA tablist，所以不用 `aria-selected`。
- **双击名字仍是改名，不会让带闪一下**：按在名字上的那一下要等双击的窗口过去（300 ms）才算单击；第二下到了就取消，改名框照常打开。按在脸上、名字旁的空白、或者用键盘，立刻生效。实现是 `EditableName` 的 `useSinglePress`，标签和窄档的头共用一个。
- **指着前标签有一句提示**（`Tooltip`，挂在标签下面，立刻出现）：收着时「点击查看近 24 小时状态」，开着时「点击收起近 24 小时状态」。这一天一段带词的都没有（全是「未查看」和空，或者节点的回答里根本没有这一行）时是「近 24 小时没有记录」，按了什么都不落，也没有 `aria-expanded`——所以不会出现一条空行。前标签挂着这句提示时不再带系统的 `title`（两个浮层叠在一枚标签上）；别的标签没有新提示。
- **记住**：全这张脸一个开关，不按会话分；存在这台设备的 `localStorage`（`khor.sessions.day`，`hooks/use-day-shown`），重开还是上次的样子。存不了（隐私窗口）就当收着。
- **打开了、一天还在路上**：这一行放一个骨架，就是带自己的几何——一颗占满整条轴的 4 px 胶囊，`fill` 底（`RegionState` 的骨架语言），不是一条空行；数据到了原地换成真带。打开了、这一天却没有记录：收起，提示说为什么。
- **窄档**没有标签条、也没有悬停：详情屏 L0 的头（「‹ 脸 名字」，`NarrowHead`）就是前标签的替身，点脸或名字开合，同一套规矩（双击名字改名，F2 也改名）。能按的样子用手机上标题菜单的写法：名字后面一个小 `⌄`（`size-3`、`tertiary`），开着时朝上；没有底、没有框。没有记录时不画 `⌄`，按钮是 `aria-disabled`。工作区会话栏里的会话不取「一天」，那里的头照旧只是名字。

## 浮在会话上，不占它的位置（2026-09-29 傍晚）

负责人：「下方多了一个空间，看起来是为了显示悬浮的内容，但挤占了session的内容呀。悬浮内容悬浮在session内容上即可。」

- 这一行**不在版式里**：它挂在一个零高的座上（宽档在标签条下、窄档在头下，原来那一行该在的地方），浮在会话最上沿。会话从板的上沿开始，带开着、收着都不挪、不变矮——以前每开一次把会话往下推 12 px，终端上这就是一次改尺寸，tmux 当着人的面重排一遍屏幕，关的时候再来一遍。
- **底是一道淡出**：从它下面那块面的颜色（终端是 `background`，别的会话是板的 `card`，`--day-under`）到透明，带所在的上三分之二是实的——工具栏下面滚过去的内容就是这个边。会话最上面一行字从带下面淡进来，不是被一刀切掉；聊天的上边距本来就是 12，静止时什么都不盖。
- **点击只归胶囊**：这一行本身不接点击，段与段之间的空、下面淡出的那一截，点到的都是会话（终端里照样能点、能拖着选字）。
- **会话里自己浮在右上角的东西让开它**：终端的标题和 ⌘F 查找条在带开着时往下让一行（`--day-over`），两样浮层不叠。

## 几何

- 带本身 4 px，坐在自己的一行里：上下各 `gap-xxs`（一行 12），左右离板边 `gap-in`——板的上角是 12 的圆，贴边的第一段和最后一段会被切成弧。
- **这一行就是它的热区，也只有这一行。** 每一段的热区上下各伸出 `gap-xxs`，正好填满这一行，不越出去：标签条的下沿是标签的，下面的内容是内容的（2026-09-29 之前热区往上伸 12、伸进标签条后面，只是被板的 `overflow: hidden` 连点击一起裁掉了，实际的靶子就是那 4 px）。
- **手指下也不加高（负责人 2026-09-29：「不加高」）。** 这一行 12 px，低于 `--touch` 44，是有意的：它每长一像素，就多盖住会话一像素（同日傍晚以前是往下挤一像素）；手机上点一段打开浮层，靠的是段宽（每格 ≥ 6 px），不是行高。check-face 的 fixture 以后若带上一天的数据、热区普查量到它，按这一条在 `UNDER_FLOOR` 里登记豁免，别去加高。
- **最短的一段也是一颗点（4 × 4）加它的 2 px 空。** 不在界面里合并短段：界面向节点要的格子至少 6 px 宽，合并交给节点自己那一套（`khor_core::DayCell::rank`，偏向「待批」）。代价是分辨率：900 宽的板上一格约 10 分钟，手机上约 23 分钟。

## 指、按、键

一段话，三条路，说的是同一件事：

- **指着**：立刻出现一个提示（`Tooltip` 的样子），挂在带的**下面**、夹在板里，写这一段的起止、词和时长——`10:05–11:55 · 待批 · 1 小时 50 分钟`。只写这一段，不写光标下那一分钟（那是一根时间轴，而这条带不画时间轴；手指也拿不到它）。
- **按 / 点**：一个浮层（`popover` + `float` + `radius-lg`，一种浮层语言），挂在这一段下面：带点的词、起止、时长；「未查看」多一句它是什么意思。手机没有悬停，这是它的路。点外面、按 Esc、再点同一段都会收起。浮层开着时提示不出现，一次只浮一样。**不放 24 小时合计**：格子是按「最想叫你的那个词」合并的，加出来的「待批 2 小时」可能是十二格里各一分钟。
- **键盘**：整条是一个 Tab 停点（`toolbar`），← → Home End 在段之间走，焦点环是 `ring`，提示跟着焦点走；⏎ / Space 打开浮层，Esc 收起、焦点回到那一段。

字全是目录的（六个词、`day-unwatched`、`day-unwatched-why`、时长的 `age-*`），` · ` 和 `–` 是标点。浮层里的字不能选：是读数，不是要抄走的值。控件上是箭头。

## 用

```jsx
<DayStrip spans={[{ width: '18%', word: 'busy' }, { width: '6%', word: 'done' }]} />
```

消费方负责：分段的宽度百分比和每一段的状态词。

## Do / Don't

- 状态色在这里是**填充**，这是六个词唯一被允许当填充用的地方——因为它是一条 4 px 的条，不是一块底，上面永远没有字。
- 不加刻度、不加时间轴、不加提示和浮层以外的任何东西。
- 别把它挪到板里面去。
- 别在界面里合并、排序或挑词：画什么是节点说的。
- 别为「还没到」或「没有记录」留一条空行：还没到是骨架，没有记录是不画。
- 别让它占会话的位置：它浮在会话上，会话不因为它挪一个像素；也别给这一行本身接点击。
- 门：`npm run day` ⓪（默认收着且不留位、落下来浮在会话上而会话不动、行上胶囊以外的一点落到会话、前标签的提示与开合、双击名字不闪、重载后还记得、没有记录不画、加载时是骨架、窄档点头开合）与 ⑥（胶囊与空、提示与浮层说同一段、手指点得开、一个 Tab 停点、热区不越出自己那一行）。

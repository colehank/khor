# EmptyState

空、出错、还没选中——三种情况共用这一个位置，居中在 R1 里。一句话（`body` 配 `secondary`），需要时下面一行指路（`hint`，`callout`），**最多一个按钮**。要标题的话用 `title-lg` 22，那是整个界面里最大的字号，所以它很少出现。

## 用

```jsx
<EmptyState hint="点击搜索框旁的 + 添加工作区">还没有工作区</EmptyState>
<EmptyState headline="待处理" action="重试">这台机器没有回应：连接在 12 秒后超时。</EmptyState>
```

消费方负责：那一句话、指路那一行、按钮文案和回调。

## Do / Don't

- **不要插画。** 一句话就够了。
- **不要两个按钮。** 有两条路就说明这里其实是一个选择，该换个做法。
- **空状态不新建东西**（2026-10-01，负责人：「空状态不加添加工作区和登记」）。会让一样新东西出现的动作只有一个家——L0 搜索框旁的 ＋（《骨架与三种页型》D9）。一个工作区、一个额度账户都没有时，板上只有那一句话，下面一行指路「点击搜索框旁的 + 添加工作区 / 登记账户」，**没有按钮**；L0 的 ＋ 必须在（空的额度页因此也画列表那一栏）。空状态留下的按钮只有「重试」：它重做失败的那一下，不新建东西。⚠️ 墓碑：09-28 到 10-01 这两处空状态各摆一颗「添加工作区…」「登记…」，D9 写着「空状态那一个按钮不算第二个家」；负责人看真 app 后撤了。`check-face` §16 d。
- 出错时用**机器自己那句话**（「连接在 12 秒后超时」），不要写「出错了，请重试」。不要红框，不要堆栈。
- 每个落地页的「没选中」状态不是空状态，是**总览**：会话 →「待处理」+ 机器（2026-09-28 由「等你的事」改名，标准词）；机器 → 那张图；额度 → 所有账户的环；工作区 →「最近打开」的工作区；更多 → 通用。

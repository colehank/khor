# StatusBar

> **2026-10-02 起是一张底加灰线**（README 颜色）：下面说的「纸」「框」「左块」都已是同一张底（`canvas` = `side` = `card`），分开元素的是 `hairline` 灰线、玻璃和选中行的灰块。这一段留作来历。

窗口最下面那一条，`ctl-sm` 22 高，`caption` 配 `tertiary`，底是 `canvas`——它是框的一部分，不是内容（2026-09-30，板是纸底是框）；上面的状态词在框上最低 4.52（亮）/ 5.05（暗）。

**它管一次性的回报**：已置顶、已复制、已关掉 3 个标签。停 2 秒然后消失。

## 用

```jsx
<StatusBar>已置顶 khor</StatusBar>
```

## Do / Don't

- **不要用盖在内容上的 toast。** 这条是它的替代品：一次性的回报不值得挡住任何东西。
- 这里不放要人回应的东西。要回应的是对话框。
- 一句话，不带按钮。
- **只在有话说时占一行**；没东西时这一条不画，窗口底下就是板的边。
- 会一直停着的只有「失败」「中断」：一个自己消失的失败等于没报。它们不配 ×，**整行就是按钮**，按一下拿掉（`aria-label`「移除 …」）。2026-09-26 之前这里是右下角一个带边框、阴影和 × 的浮块——正是上面禁止的 toast。
- 持续的状态（「正在同步」）不属于这里——那是区域状态的事。

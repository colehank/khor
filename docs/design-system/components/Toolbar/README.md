# Toolbar

右边的第一行（R0），高 `pane-head` 48，**每一页都有**。两种形态：

- **`variant="title"`**（页型 A）——**只有**页面标题（`title-sm` 15）和右端的页面按钮，左边不放后退/前进（D2，2026-09-26 改）。详情页永远和它的列表并排，选过什么列表上看得见，再加一对箭头走一遍是重复的。
- 页型 C 是例外：那对 ‹ › 和 ⟳ 走的是**网页自己的历史**，属于地址栏，不属于这一行的标题。
- **`variant="tabs"`**（页型 B）——标签条 + ＋。

页型 C 用 `address` 顶掉标题：那一行本身就是地址栏。

**页面级按钮只在这里，只在右端**（D9）。行的动作在右键菜单。不许两边都有。「…」页也一样：安全页的「立即锁定」不是设置、也不是哪一行的动作（开关那一行说的是锁存不存在，它是去用它），所以它是这一页的按钮，锁开着时站在 R0 右端、「×」左边（2026-09-28；以前是卡片里一颗左对齐的孤按钮）。页面在自己那一层写它（`PageAction`），外壳把它放进 R0；窄档没有 R0，它在 L0 那条头的右端。

**窄档没有这一行**：详情屏的头坐进 L0（「‹ 名字 · 页面按钮」），见 `SideHead`。

## 用

```jsx
<Toolbar title="外观" />
<Toolbar title="turing" trailing={<><Button size="sm">唤醒</Button>…</>} />
<Toolbar address="lan.cibol.khor.cloud/plans" />
<Toolbar variant="tabs" trailing={<Button kind="plain" icon="plus" />}>{tabs}</Toolbar>
```

消费方负责：标题或地址、历史能不能走、右端按钮。

## Do / Don't

- **身份只出现一次**：R0 的标题（A、C）或者标签（B）。板里**不许**再有第二个标题。
- **R0 和 R1 之间什么都不许加**：不加副标题行，不加状态句。会话页那条 4 px 的「一天」是唯一的例外，而且它没有文字。
- 「过期 / 离线」那行字挂在 R0 **右端**，用 `caption`，不是板里的横幅。
- 这一行的空白处拖窗口。

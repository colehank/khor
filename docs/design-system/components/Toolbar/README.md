# Toolbar

右边的第一行（R0），高 `pane-head` 38（2026-09-29 由 48 收紧；指针是手指时 48），**每一页都有**。里面的东西——标题、标签的签、页面按钮、地址栏——都在这一行的中线上，和 L0 的搜索框、三颗窗口按钮同一条线。两种形态：

- **`variant="title"`**（页型 A）——**只有**页面标题（`title-sm` 15）和右端的页面按钮，左边不放后退/前进（D2，2026-09-26 改）。详情页永远和它的列表并排，选过什么列表上看得见，再加一对箭头走一遍是重复的。
- 页型 C 是例外：那对 ‹ › 和 ⟳ 走的是**网页自己的历史**，属于地址栏，不属于这一行的标题。
- **`variant="tabs"`**（页型 B）——标签条 + ＋。

页型 C 用 `address` 顶掉标题：那一行本身就是地址栏。

**两行标题**（2026-09-28）：标题下面可以有第二行，`callout` 配 `secondary`，两行一起在 R0 里居中——字号 15 / 12 不变，行距各收一档（名字 18、第二行 14，共 32，上下各留 3；2026-09-29 R0 收到 38 时）——macOS 的标题 + 副标题，不是 R0 和 R1 之间多出来的一行。**A 页型的每一页都是两行**（2026-09-30 改，负责人：「所有非标签页的落地页和工作区看齐」）：机器页是机器名、下面 `khor 0.1.14 · 12 秒前`；额度、「…」各页各写自己已经问到的那个事实，每页写什么是《骨架与三种页型》页型表旁边那张表。**只写页面已经问到的事实**，没有诚实的事实就不画第二行（外观），不编。⚠️ 墓碑：09-28 这里写的是「只给有『位置』要交代的页……机器、额度、『…』页的名字已经说全了，不加」，版本和读数年龄于是挂在 R0 右端；那一端现在只留整页过期时的那一句（`RegionState` `stale`）。第二行由页面写（`PageSubtitle`），外壳摆（`Region` 的座位），和 `PageAction` 同一个机制；窄档没有 R0，页面自己的头（`NarrowHead`）说放得下的那一段。

**名字旁边的字**（2026-09-30，打开的工作区：「⎇ main」）：修饰名字的短事实站在名字那一行、名字的基线上，`callout` 配 `secondary`、`caption` 的行距（`PageTitleAside`），不把名字那一行撑高；放不下先让它们缩，名字最后才让。**只有分支，不写改动的文件数**（同日负责人：「还是不写多少个文件已修改这样的 git 注释吧」；早上那句「标题旁边是 git branch 加改动简介」里的「改动简介」撤了）：「N 个文件已修改」留在工作区列表那一行的角上——那是扫哪个工作区有活干的地方；页头是你已经在的地方，只说在哪。第二行于是只留那一个长值——位置。第二行里的位置太长时从中间截（留下机器和最后一段），截了才用提示说出整个值；它是能拷走的值，所以能选（`data-selectable`），并且带一个焦点位——R0 会拖窗口，没有焦点位的字按下去是拖窗口，不是选字。

**页面级按钮只在这里，只在右端**（D9）。行的动作在右键菜单。不许两边都有——总览上也一样：会话总览的「待处理」那一行不再挂「新会话…」，那一扇门是 R0 的（2026-09-28）。「…」页也一样：网络页的「邀请设备…」「加入网络…」、安全页的「立即锁定」都是这一页的按钮，站在 R0 右端、「×」左边。「立即锁定」不是设置、也不是哪一行的动作（开关那一行说的是锁存不存在，它是去用它），锁开着时才出现（2026-09-28；以前是卡片里一颗左对齐的孤按钮）。**一个机制**：页面在自己那一层写它们（`MoreFrame actions` → `PageAction`），宽档外壳把它们放进 R0，窄档放在 L0 那条头的右端。

**R0 的图标按钮是工具栏控件，不是竖栏字形**（2026-09-28）：ghost 方块 `ctl-md`，热区跟 `--hit`（指针 28、手指 44），每一颗配一个 `Tooltip` 说它的名字。字形用竖栏同一个 24 画布的形，**画成它自己的 24**（2026-09-30 负责人：「顶部右侧的几个 icon 太小了，明显没有把空间充分利用上」；09-28 到 09-30 画的是 20，「…」列表的尺寸，三颗放在 38 的行里大半是空气）。24 的形不缩到 16 画布，见 `Icon`；机器详情 R0 那三颗（开会话、看文件、借网）更早是竖栏尺寸 32，比 15 的标题还重——32 太重、20 太轻，24 是 28 的方块里留 2 的那一档。VS Code 的标记按「墨等量」配：气泡在自己的画布里留气、24 画出约 17 的墨，标记画满、盒子 16（`check-face` 4l 量的是墨，不是盒子）。16 画布的行内标记（「…」页的 ×、标签条的 ＋）照旧画成 16，不放大——描边比例是画布的。

**R0 的文字按钮是默认的 push**（2026-09-30）：`ctl-md` 28、`body` 13（「新会话…」「导入…」「邀请设备…」「加入网络…」「注册账户…」「立即锁定」，`PageActions` 一处出）。以前是 `sm`（22、`callout` 12）再被 `min-h-touch` 撑到 28：一颗 28 高的按钮穿着 12 的字和 8 的内距，在 38 的行里读成小按钮。`sm` 只给密排的行（`Button`）。

**窄档没有这一行**：详情屏的头坐进 L0（「‹ 名字 · 页面按钮」），见 `SideHead`。

## 用

```jsx
<Toolbar title="外观" />
<Toolbar title="turing" trailing={<><Button size="sm">唤醒</Button>…</>} />
<Toolbar address="lan.cibol.khor.cloud/plans" />
<Toolbar variant="tabs" trailing={<Button kind="plain" icon="plus" />}>{tabs}</Toolbar>
```

消费方负责：标题或地址、历史能不能走、右端按钮。

## Do / Don't

- **身份只出现一次**：R0 的标题（A、C）或者标签（B）。板里**不许**再有第二个标题。
- **R0 和 R1 之间什么都不许加**：不加副标题行，不加状态句。会话页那条 4 px 的「一天」是唯一的例外，而且它没有文字。（上面的两行标题在 R0 **里面**，不是这一条的例外。）
- 图标按钮开着的样子是 `fill-strong` 的灰块、满值 `ink`，不是品牌绿（2026-09-28：工作区的会话栏开关以前用 `rail-on-ink`）。
- 「过期 / 离线」那行字挂在 R0 **右端**，用 `caption`，不是板里的横幅。
- 这一行的空白处拖窗口。

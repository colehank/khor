# Avatar

身份。默认是 `lq1 → lq3` 的 135° 渐变——这三档橄榄绿是 `crates/core/src/avatar.rs` 那套调色板的镜像，也是橄榄绿在这套系统里保留的第一个岗位。外沿一圈 `avatar-edge`，让浅色头像从浅色底上分得出来。

三档尺寸：`avatar` 32 在列表行里，`avatar-lg` 72 在详情页顶部，`avatar-xl` 96 在总览里。永远是 `radius-full`。

角标尺寸：规格原写 15 的圆；app 里是 `kind-mark` 18、`radius-sm` 的方块——负责人 2026-09 初嫌 11 看不清放大过，这里以那次裁定为准。标签上的 16 的脸配 `kind-mark-tab` 12 / 10（见 `Tab`）。额度那一环**没有角标**（2026-09-30）：类型的标记是那一行标题的开头（「✳ Claude Code 订阅」，负责人：「把类型的头像做成标题的开头」），环里的读数整个露着。~~2026-09-28 起角标站在环旁边（`FaceMark` 的 `beside`），因为压在环上会吃掉「39%」「124$」的最后一个字~~——`beside` 随它唯一的用处一起退了。1.5 的 `side` 切口圈在 macOS 的侧边栏材质上是透明的（`--side` 被清空），所以 app 里没画。

角标（`mark`）说的是**这是哪一类**：`chat` 对话、`terminal` 终端、`link` 借来的连接。它坐在右下角，底是 `card`，外面一圈 1.5px 的 `side` 把它从头像上切开。

## 类型标记的两种画法（2026-10-02，负责人）

负责人看了示意图：「画在脸上感觉很好看。我们在外观里可以设置，对象类型的绘制形式，角标、浮现这样。不做对调了，就是这两种选择。」凡是「机器的脸 + 这是哪一类」的头像——会话行（claude / codex / 终端 / 留言…）、机器行（系统）、工作区行（仓库 / 文件夹）、浏览标签行（网站图标 / 页面）、标签页上的脸、窄档详情头——只有一个组件画：`FaceMark`（`apps/gui/src/components/FaceMark.tsx`），由「…」→ 外观 →「类型标记」决定画法，切换立刻全 app 生效。

| | 浮现（`face`，**默认**） | 角标（`corner`） |
|---|---|---|
| 标记在哪 | 脸的正中，**没有角标** | 脸的右下角，`card` 底的切块 |
| 标记多大 | 行里 `kind-mark` 18 落在 32 的脸上（四边各 7）；标签上 `kind-mark-tab` 12 落在 16 的脸上（四边各 2） | 和以前一样：`kind-mark` 18 / 14，标签 12 / 10 |
| 墨 | `mark-ink` 白，两个主题同一个 | `muted-foreground` |
| 脸 | 压一层 `mark-veil`（黑 0.42），随脸的裁形（圆 / 圆角 / 方）；**笑脸不画五官** | 原样 |

一个头像同时说两件事：形状是哪一类，颜色是哪台机器。

- **看得清，用的是「一层罩 + 一种墨」**，不按每张脸挑黑白墨、也不切缝：脸是渐变，一张脸里同时有亮有暗，挑哪种墨都有一半会糊；切缝要给每个别人的标记（实心的品牌标、走线的家族字形）都造一圈遮罩。罩的值是**界**，不是口味：脸能有的最亮是白（自己调的色板可以有 `#ffffff`，晕染的叠加笔还会比任何一格更亮），白压 42% 黑亮度 0.296，白墨 3.04 ≥ 图形的 3:1——**任何色板画出的任何脸都过**。示意图里那层 0.30 在同样的脸上最差 2.27（`check-palette` 故意改坏时量到的）。
- **实测**（`check-palette`「a mark on a face」，七种出厂色板 × 三种画法 × 十六台机器的真脸，标记字形占的那一块里最亮的像素对白墨；两个主题读数相同，因为脸和罩都不读主题）：液态 3.24 / 3.35 / 3.35（晕染 / 几何 / 笑脸）、Monokai 3.73 / 4.11 / 4.11、Mocha 3.41 / 3.72 / 3.72、Nord 3.83 / 4.41 / 4.41、Okabe-Ito 3.69 / 3.87 / 3.87、暖纸 3.68 / 4.03 / 4.03、纸墨 3.25 / 3.25 / 3.25；没有脸的空白圆（也压罩）浅色 3.65、深色 17.78。最差 3.24（液态晕染）。
- **标记的实心块填满**（`app.css` `[data-mark-at="face"] svg [data-body]`）：家族的 `icon-body` 0.7 在脸上会把白往脸色拉回去，白脸上只剩 2.3。这借的是竖栏「打开」那一条规矩：实心块填到 1.0，家族的切缝照样把几块分开。
- **笑脸（beam）在浮现时不画眼睛和嘴**：五官正好在标记要占的正中，叠在一起读成一块污迹。留下的底色和那块圆角方块仍是这台机器的颜色和摆法。**只在标记底下这样**：机器详情、编辑窗、「这台机器」、竖栏底下自己的头像、锁屏，这些不说类型的地方脸照旧完整（`Avatar.tsx` 的 `UnderMark` 只由 `FaceMark` 设）。没有任何一个 `avatar.rs` 推出来的数变了。
- **状态照旧**：会话的光晕画在脸的盒子外面，两种画法是同一圈。
- **一倍屏干净**：浮现没有任何 1 像素的环；标记 18 / 12、边距 7 / 2 全是整像素（负责人的显示器是 2560×1440 一倍屏，`check-face` 第 17 节量）。
- **小尺寸不简化、不换角标**：标签上的脸只有 16，标记从角标的 10 放到 12——10 的时候终端那几笔不到一个像素，几何脸自己的色块会从笔画里透出来。放在哪由设置一处决定，尺寸不另开例外。
- 别人的标记（Claude、Codex、苹果、Linux…）原样画、用墨；网站图标是一张图，原样画在脸上，不染墨。
- 锚点：标记两种画法都带 `data-side-mark`（它说的是哪一类）和 `data-mark-at`（`face` / `corner`）；只有角标是 `data-side-badge`；脸上的罩是 `data-face-veil`。
- 别处要一枚「机器 + 系统」的头像（机器页页头），用 `SessionFace.tsx` 的 `MachineFace`——就是机器行那一枚，跟着设置走。额度行没有脸，标记是标题的开头，不涉及。

## 用

```jsx
<Avatar size={32} mark="terminal" />
<Avatar size={72} from="#9cc19a" to="#c9523f" />
```

app 里：`<FaceMark face={<MachineAvatar … />} mark={sessionKind(kind, category)} halo={word} />`；标记由 `FaceMark` 按尺寸画（`KindMark.glyph(className)`），列不自己定标记的大小。

消费方负责：尺寸、两端颜色（从后端那套调色板来，不要现编）、角标。

## Do / Don't

- 颜色从 `avatar.rs` 那套里取，**不要**当场算一个 hash 出来的颜色——同一个身份在两处必须同色。
- 头像上不写字。要缩写的场合说明这个东西还没有身份，应该用一个字形而不是首字母。
- 标签条上那个 16 的脸是同一套渐变，但它不是 `Avatar`，它是 `Tab` 自己的 `k-tab-face`。
- **R0 的类别头像不是脸**（2026-10-01，负责人：「头像仅仅是类别头像哈，不是机器带角标的」「类别头像机器就是系统的 icon 呀，额度页就是厂商的 icon 呀」）：A 页型打开一台机器、一个额度账户时，R0 两行标题左边那一枚是 `avatar` 32 的圆盘，底是纸 `card`、外沿一圈 `avatar-edge`（和脸一样的边，读成头像），里面是**这一类**的标记——系统的（苹果、Linux…，列表行角标同一枚）或厂商的（Claude、Codex…）——原样画成 `kind-mark` 18，墨 `ink`。它没有渐变、没有角标，也不是 `Avatar`（`Region` 的 `PageAvatar`）。机器自己的脸在列表行和名片里。
- **一台机器的脸只有一处能改**（2026-09-30）：机器行右键「编辑…」的窗口（`MachineEditDialog`，脸那半是 `FaceSettings`）。「这台机器」页只画它（`kind-mark` 18 的一枚，挨着名字），机器详情的名片画 `avatar-lg` 72 的那张。编辑窗里的大脸是 `avatar-xl` 96，是编辑的对象，也是唯一的预览——选项是分段控件的字，不再各带一张缩略图。

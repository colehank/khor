# Avatar

身份。默认是 `lq1 → lq3` 的 135° 渐变——这三档橄榄绿是 `crates/core/src/avatar.rs` 那套调色板的镜像，也是橄榄绿在这套系统里保留的第一个岗位。外沿一圈 `avatar-edge`，让浅色头像从浅色底上分得出来。

三档尺寸：`avatar` 32 在列表行里，`avatar-lg` 72 是机器地图上这台机器的脸的下限，`avatar-xl` 96 在总览里。永远是 `radius-full`。（`avatar-lg` 09-30 → 10-01 也是机器详情顶上名片的那张脸，名片撤了，见下。）

角标尺寸：规格原写 15 的圆；app 里是 `kind-mark` 18、`radius-sm` 的方块——负责人 2026-09 初嫌 11 看不清放大过，这里以那次裁定为准。标签上的 16 的脸配 `kind-mark-tab` 12 / 10（见 `Tab`）。~~额度那一环**没有角标**（2026-09-30）：类型的标记是那一行标题的开头（「✳ Claude Code 订阅」，负责人：「把类型的头像做成标题的开头」），环里的读数整个露着~~——2026-10-06（UX-32）起额度行的头像是账户所在机器的脸戴厂商标记，环挪到右上（见下「一个装配，三种画法」）。~~2026-09-28 起角标站在环旁边（`FaceMark` 的 `beside`），因为压在环上会吃掉「39%」「124$」的最后一个字~~——`beside` 随它唯一的用处一起退了。1.5 的 `side` 切口圈在 macOS 的侧边栏材质上是透明的（`--side` 被清空），所以 app 里没画。

角标（`mark`）说的是**这是哪一类**：`chat` 对话、`terminal` 终端、`link` 借来的连接。它坐在右下角，底是 `card`，外面一圈 1.5px 的 `side` 把它从头像上切开。

## 类型标记的两种画法（2026-10-02，负责人）

负责人看了示意图：「画在脸上感觉很好看。我们在外观里可以设置，对象类型的绘制形式，角标、浮现这样。不做对调了，就是这两种选择。」凡是「机器的脸 + 这是哪一类」的头像——会话行（claude / codex / 终端 / 留言…）、机器行（系统）、工作区行（仓库 / 文件夹）、浏览标签行（网站图标 / 页面）、标签页上的脸、窄档详情头——只有一个组件画：`FaceMark`（`apps/gui/src/components/FaceMark.tsx`），由「…」→ 外观 →「类型标记」决定画法，切换立刻全 app 生效。

| | 浮现（`face`，**默认**） | 角标（`corner`） |
|---|---|---|
| 标记在哪 | 脸的正中，**没有角标** | 脸的右下角，`card` 底的切块 |
| 标记多大 | 行里 `kind-mark` 18 落在 32 的脸上（四边各 7）；标签上 `kind-mark-tab` 12 落在 16 的脸上（四边各 2） | 和以前一样：`kind-mark` 18 / 14，标签 12 / 10 |
| 墨 | **按脸换**：亮脸 `mark-ink-dark`（暖近黑），暗脸 `mark-ink-light`（白），不透明；两个主题同一个。没有脸的空白圆用 `mark-ink-blank`（随主题） | `muted-foreground` |
| 脸 | **大多不压**；只有中心明暗混杂的脸压一层罩，只压到够——亮墨下压黑 `mark-veil-dark`、暗墨下压白 `mark-veil-light`，透明度是这张脸自己的（最多 0.42），随脸的裁形（圆 / 圆角 / 方）；**笑脸不画五官** | 原样 |

一个头像同时说两件事：形状是哪一类，颜色是哪台机器。

### 一个装配，三种画法（2026-10-06，UX-32，负责人在原型 `audit/khor-faces.html` 上定）

**底座永远是「谁的」——机器的脸，没有例外；标记是「什么」。** 每一行、每个标签胶囊的身份位都是这一个装配（`FaceMark`）：机器行的标记是系统（macOS 戴 Finder、iPhone 戴 Apple 标，UX-27）、会话行是 终端 / 对话 / 厂商、工作区行是 文件夹 / 分支、文件标签是文件类型的字形（树里那一套 `FileKindIcon`，一张图，不染墨）、浏览页是**网页自己的 favicon**、额度行是厂商的标记（Claude、OpenAI）。标记都在 `SessionFace.tsx` 里各造一处（`machineKind` `sessionKind` `workspaceKind` `fileKind` `pageKind` `providerKind`），没有哪个界面自己画。

设置在 外观 → **头像**，两项：「类型标记」浮现 / 角标；选了角标才画出「角标是」类型 / 机器（用不上的控件不画）。于是三种画法：

| | 浮现（`face`，默认） | 角标 · 类型（`corner` + `kind`） | 角标 · 机器（`corner` + `machine`） |
|---|---|---|---|
| 底座 | 机器的脸 | 机器的脸 | **标记的字形**落在一块中性圆盘上（`fill-strong`、`muted-foreground`）；网页则是 favicon 本身 |
| 标记在哪 | 脸的正中 | 脸右下角的切块 | 就是底座 |
| 机器在哪 | 底座 | 底座 | **右下角**，脸画成角标的尺寸（行 14、标签 10），圆的，`card` 底 |
| 锚点 `data-mark-at` | `face` | `corner`（`data-side-badge`） | `base`（`data-mark-base`；角上的脸 `data-face-corner`） |

`kind-mark` 键和存的值都没动，所以之前选的角标照旧；`corner-is` 是新键，默认 `kind`。外层 `data-mark-way` 说画的是哪一种。

**文件是唯一的例外：脸就是文件类型**（UX-45，2026-10-07，负责人：「全都只有文件类型」）。凡是画一个文件的地方——宽档的文件标签、手机文件页甲板上的药丸、附栏最近里的文件行、标签面板和切换器的行、用 `fileKind` 造的任何一行——`FaceMark` 遇到 `mark.key === "file"` 就只画那枚文件类型的图标（`data-file-kind-face`）：标签里填满脸的盒子，行和别的尺寸里占 70%；**没有机器的脸、没有角标**，三种画法都一样。那台机器由这一行的字说。目录、网页、会话照旧是上面的装配。⚠️ 墓碑（UX-32 → UX-45，只对文件）：文件类型当标记画在机器的脸上。

**额度行**（同一天）：底座是账户所在的机器，标记是厂商；环从头像挪到**右上**当状态（它是一个读数，读数靠右）——`Face.tsx` 的 `Glyph`，16 的同一张 210° 表，旁边是读数（「45%」「124$」）或不正常时的状态词；右下仍是读到它的时间；左上 账户名 · 副标「Claude 订阅」；左下「剩 62% · 周三 14:00 重置」。

- **看得清，靠「按脸换墨，不够才压」**（2026-10-02，负责人在真脸上比了六种做法后选的 E）：每张脸自己说用哪支墨、压多少罩——`khor_core::avatar` 推出来，跟着脸走（`Avatar.mark`：`ink` 是 `light` / `dark`，`veil` 是罩的透明度），画笔只照画，所以手机和桌面上同一台机器的标记一样。规则（`crates/core/src/avatar/mark.rs`，不认字形）：
  1. **看哪一块**：脸中心、直径为边长 75% 的圆，和脸的裁形取交——标签上 16 的脸里 12 的标记正好是它，行里 32 上的 18 在它里面。
  2. **用哪支墨**：这一块里**多数像素**要哪支——暗墨和亮墨各自对裸脸的对比取**中位数**，大的赢（相等给暗墨）。按「哪支要的罩少」挑会让洗白的藏青脸配上暗墨，看着不对，弃了。
  3. **压多少**：0.02 一档，取最小的那档，让这一块里**最差的一个像素**对墨到 3.2；亮墨下压黑、暗墨下压白，按 CSS 的 sRGB 混色算。不容忍分位数——实验里只要放过任何一点，真字形的笔画就会正好落在被放过的像素上、跌破 3。黑罩最多 0.42（原先那层统一的罩：白压 0.42 黑后白墨还有 3.04），到顶就停在那。
  4. **标记不透明**（负责人「还是不透明吧」）。⚠️ 墓碑：80% 的透明度量过——336 张样脸里不压罩的从 269 掉到 263；60% 只剩 95，还有 10 张怎么压都到不了 3:1。没有这个字段、没有 token、没有常量。
  - 为此核心里有一个只画「标记底下那一块」的小光栅：晕染是两块直边多边形，在**自己的坐标里**按 σ = `blur` 高斯模糊（SVG 的 `userSpaceOnUse` 滤镜跟着元素的 `scale` 走），先按滤镜区域裁，叠加笔用 `overlay`；几何是硬边的方块和圆；笑脸只画外面那块（五官在标记下本来就不画）。和浏览器在 336 张样脸上逐张比：墨一张不差，罩有 5 张晕染差一档（浏览器多 0.02），其余全同。
- **实测**（`check-palette`「a mark on a face」，七种出厂色板 × 三种画法 × 十六台机器的真脸，标记字形占的那一块里对**这张脸给的墨**读得最差的像素——亮墨取最亮、暗墨取最暗；两个主题读数相同，因为脸、墨和罩都不读主题）：336 张里 **269 张不压罩**，暗墨 294 / 亮墨 42，最大的罩 0.42。逐色板最差（晕染 / 几何 / 笑脸）：液态 3.23 / 3.22 / 3.22、Monokai 4.82 / 4.79 / 4.88、Mocha 7.95 / 7.98 / 7.98、Nord 4.52 / 4.52 / 4.52、Okabe-Ito 4.68 / 4.04 / 4.78、暖纸 5.10 / 5.10 / 5.10、纸墨 3.23 / 3.25 / 3.32；空白圆浅色 15.02、深色 14.77。最差 3.22（液态几何 / 笑脸）。
- **空白圆不是脸**：没有身份、没有记录可读，它本来就是主题的 `muted` 灰，所以标记用随主题的 `mark-ink-blank`——亮色是暗墨、暗色是亮墨，都不压罩。
- ⚠️ 墓碑（2026-10-02 同日）：第一版是「一层罩 + 一种墨」——每张脸都压 `mark-veil` 黑 0.42、标记一律 `mark-ink` 白。0.42 是界（任何色板的任何脸都过 3:1，最差 3.24），但它把每张脸都压灰了。负责人：「浮现这，给原始头像上了蒙板？感觉没那么好看了」。当时否掉「按每张脸挑黑白墨」的理由是「脸是渐变，一张脸里同时有亮有暗，挑哪种墨都有一半会糊」——现在的答案是：按多数挑墨，只给真混杂的脸压、只压到最差那一点够。
- **标记的实心块填满**（`app.css` `[data-mark-at="face"] svg [data-body]`）：家族的 `icon-body` 0.7 在脸上会把白往脸色拉回去，白脸上只剩 2.3。这借的是竖栏「打开」那一条规矩：实心块填到 1.0，家族的切缝照样把几块分开。
- **笑脸（beam）在浮现时不画眼睛和嘴**：五官正好在标记要占的正中，叠在一起读成一块污迹。留下的底色和那块圆角方块仍是这台机器的颜色和摆法。**只在标记底下这样**：机器详情、编辑窗、「这台机器」、竖栏底下自己的头像、锁屏，这些不说类型的地方脸照旧完整（`Avatar.tsx` 的 `UnderMark` 只由 `FaceMark` 设）。没有任何一个 `avatar.rs` 推出来的数变了。
- **状态照旧**：会话的光晕画在脸的盒子外面，两种画法是同一圈。2026-10-15：用 mask 的真实圆环和透明间隙，列表仍为 2px / 2px，标签仍为 1.5px / 1.5px；不再用背景色阴影遮盖出间隙，透明窗口也不能把间隙变成粗状态环。
- **一倍屏干净**：浮现没有任何 1 像素的环；标记 18 / 12、边距 7 / 2 全是整像素（负责人的显示器是 2560×1440 一倍屏，`check-face` 第 17 节量）。
- **小尺寸不简化、不换角标**：标签上的脸只有 16，标记从角标的 10 放到 12——10 的时候终端那几笔不到一个像素，几何脸自己的色块会从笔画里透出来。放在哪由设置一处决定，尺寸不另开例外。
- 别人的标记（Claude、Codex、苹果、Linux…）原样画、用墨；网站图标是一张图，原样画在脸上，不染墨。
- 锚点：标记三种画法都带 `data-side-mark`（它说的是哪一类）和 `data-mark-at`（`face` / `corner` / `base`）；只有角标是 `data-side-badge`；浮现时标记带 `data-mark-ink`（`light` / `dark` / `blank`）；脸上有罩时是 `data-face-veil`（值是罩的颜色 `dark` / `light`）。
- 别处要一枚「机器 + 系统」的头像（机器页页头），用 `SessionFace.tsx` 的 `MachineFace`——就是机器行那一枚，跟着设置走。额度行没有脸，标记是标题的开头，不涉及。

## 用

```jsx
<Avatar size={32} mark="terminal" />
<Avatar size={72} from="#9cc19a" to="#c9523f" />
```

app 里：`<FaceMark face={{ machine: row.face }} mark={sessionKind(kind, category)} halo={word} />`——机器的脸交的是**记录**，不是画好的节点：`FaceMark` 自己画脸，标记的墨和脸的罩读的是同一份记录（`Avatar.mark`），不可能属于两台机器。不是脸的东西（额度的环）交 `{ art }`，上面不画标记。标记由 `FaceMark` 按尺寸画（`KindMark.glyph(className)`），列不自己定标记的大小。

消费方负责：尺寸、两端颜色（从后端那套调色板来，不要现编）、角标。

## Do / Don't

- 颜色从 `avatar.rs` 那套里取，**不要**当场算一个 hash 出来的颜色——同一个身份在两处必须同色。
- 头像上不写字。要缩写的场合说明这个东西还没有身份，应该用一个字形而不是首字母。
- 标签条上那个 16 的脸是同一套渐变，但它不是 `Avatar`，它是 `Tab` 自己的 `k-tab-face`。
- **R0 的头像**（2026-10-01；机器那一半 2026-10-02 改，负责人经领队：「机器页页头的头像不要画裸的系统标记了，直接用列表那一行的同一个机器头像组件」）：A 页型打开一台机器时，R0 两行标题左边是**列表那一行的头像本身**——脸（`MachineAvatar`，`avatar` 32）加系统标记，列表行怎么画（「浮现」或「角标」）这里就怎么画（`FaceMark`）；打开一个额度账户时是**厂商的标记本身**（Claude、Codex…），原样画成 32、墨 `ink`，没有脸、没有角标。**R0 里没有 1 像素的圈**：这里拿掉脸的 `avatar-edge` 细边（`Region` 的 `PageAvatar` 把座位里脸的边框清零），后面也不垫圆盘。负责人：「这个标题上的头像也太难看了，有一个我屏幕上看起来带锯齿的边」——一倍屏上 1 像素的圆圈必然锯齿。**和开头那条「外沿一圈 `avatar-edge`」打架，选了一倍屏上干净**：那圈边是给浅色的脸落在**纸**上分出来用的；R0 是框的灰（`canvas`），不是纸，而一倍屏上的锯齿是负责人亲眼看到的。代价：极浅的脸在浅色 R0 上会淡一点（验收清单里让负责人看）。⚠️ 墓碑（2026-10-01 → 10-02）：先是 `kind-mark` 18 的类别标记垫在一枚 `avatar` 32 的纸色圆盘上（外沿 `avatar-edge`，「和脸一样的边，读成头像」）——锯齿，18 的标记外面空一圈像徽章；再是系统标记本身画成 32（同一晚，没合进 main）。
- **一台机器的脸只有一处能改**（2026-09-30）：机器行右键「编辑…」的窗口（`MachineEditDialog`，脸那半是 `FaceSettings`）。「这台机器」页只画它（`kind-mark` 18 的一枚，挨着名字）；机器详情的板里**不画**它（2026-10-01 晚：名片撤了，换成事实带——那张 72 的脸和左边列表那一行是同一张，不传达新信息；09-30 → 10-01 名片画的是 `avatar-lg` 72 的那张）。编辑窗里的大脸是 `avatar-xl` 96，是编辑的对象，也是唯一的预览——选项是分段控件的字，不再各带一张缩略图。

### 会话内容与主区同一身份（2026-10-18）

会话内的工作区标题读取与主区相同的 checkout 判断，不凭分支名是否为空判断 Git 仓库；普通目录仍戴文件夹。桌面嵌套标签、手机标签列表的网页，用相同的 `pageKind` / `TabAvatar` 装配和节点 favicon 缓存；图标通过页面自己的出口获取，没有图标时才回退浏览器字形。迟到请求按原请求网址归属，不能覆盖新页面。文件继续只画文件类型；手机内容药丸的会话头像继续表示所属会话。

模型回归：`npm run content-model`。真实 App 验收：仓库／普通目录／detached HEAD、桌面与手机网页图标、重开缓存、跨站切换回退、药丸收起同时关闭侧区。

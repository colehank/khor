# Switch

是 / 否。`switch-w` 32 × `switch-h` 18，圆角 `radius-full`，打开时槽是 `brand-strong`，关闭时是 `fill-strong`；那颗钮永远是白的——颜色是 `knob` 这个 token（两个主题都是白，2026-09-28 之前组件里写的是字面量 `bg-white`），带 `shadow-knob` 这一档阴影——全系统唯一的一处阴影例外。

灰掉的开关整颗 0.5 透明度，**光标还是箭头**：AppKit 在不可用的控件上不换光标，`not-allowed` 那个带斜杠的圆是网页的说法（`check-face` §11b）。

**只用在一件事立刻生效、而且只有两种状态的时候。** 要在几个里选一个用 `PopupButton`；有自己一页的用导航行；只做一次的动作用按钮。

## 用

```jsx
<Switch on={confirmBeforeDelete} label="删除前确认" onChange={set} />
```

消费方负责：`on`、`onChange`、以及 `label`——开关自己不带文字，标题在它左边的设置行里，屏幕阅读器要靠 `label`。

## Do / Don't

- 切换**立刻生效**，不要再跟一个「保存」。做不到立刻生效的，说明它不是开关。
- 文案写肯定式（「删除前确认」），不要写「不要在删除前确认」——否定式的开关要在脑子里多转一道。
- 需要解释的，把一句话放在 `note` 里（`callout` 配 `secondary`），别放在开关旁边。
- 动画 `dur-180` `ease-out`，只有槽色和钮的位移两件事在动。
- 在设置行里，**槽的右缘就是行的右缘**，和按钮、弹出按钮对齐；热区比槽大时往左长，不往右越线（2026-09-28）。

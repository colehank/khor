# Rail

竖栏（L1），宽 `rail-w` 64，右边一条 `hairline` 把它和列表分开（那条线从 L0 下面才开始）。每一项是 `rail-item` **48 × 48 的正方框**、`radius-md` 8 的角，里面一个 24 画布的字形（放在 `icon-rail` 32 的框里）。项与项之间 `gap-xxs` 4，节距 52。

**高和宽都是 `rail-item`，不跟控件热区走。** 2026-09-26 鼠标下的热区从 44 降到 `ctl-md` 28 时，竖栏项曾经跟着缩成 28 高、节距 32，负责人说「侧边栏的 icon 间距过小」。竖栏是导航，不是控件，它的尺寸是自己的。

每一项有一个名字提示（`Tooltip`），指过去立刻出现在右边；窄档没有指针，不出现。

下面依次是：五个落地页 · 「…」更多（`pushDown`，贴底）· 这台机器的头像。

## 打开的那一项：变的是图标的彩度，不是它的背景

| | 墨 | 实心块（`data-body`） | 底 |
|---|---|---|---|
| **未打开** | `rail-ink` 6.32 / 8.51 | `icon-body` 0.7 → 3.24 / 4.76 | 无 |
| **指过去** | `rail-ink` | 0.7 | `fill` |
| **打开** | **`rail-on-ink` 深橄榄绿** 9.75 / 14.48 | **1.0** | **无** |

## 这三个数字是门定的，不是审美定的

`scripts/check-rail.mjs` 对这一块有三条硬约束，改任何一个值之前先读它们：

| 门 | 要求 | 现值 |
|---|---|---|
| `LINE_FLOOR` | 未打开的**描边**不低于 亮 4.7 / 暗 5.5 | 6.32 / 8.51 |
| `FLOOR` | 未打开的**实心块**（墨 × `icon-body`）不低于 3.0 | 3.24 / 4.76 |
| `GLYPH_MARGIN` | 打开的描边比未打开的**高出 2.0**，静止和**被指着**两种底上都要过 | 静止 +3.43 / +5.97，悬停 +2.35 / +3.71 |

所以「把未打开的调淡，让打开的靠色相跳出来」——macOS 侧边栏那套——**在这副骨架下是关死的**：亮色把墨降到 0.68，实心块就掉到 3.00；降到 0.60 是 2.57。要走那条路得先重写 `GLYPH_MARGIN`，那是另一件事。

## 被修好的是彩度，不是亮度

打开态之前是 `#303a19`，数字很漂亮（`side` 上 10.06），但看不出是绿的。原因在推导方式：它是「和 `lq3` 同色相、同饱和度，把亮度压下来」——那是一个 **HSV 动作，而在 HSV 里压亮度会把彩度一起丢掉**。量出来 `#303a19` 在 OKLCH 里只有 **C 0.054**，而它那个亮度上橄榄色相的上限是 **0.084**：**只花掉了 64%**。眼睛看到的就是「另一种深墨」。

改法：锁死色相 124.8°，**取该亮度允许的最大彩度**，让亮度落在门需要的地方。

| | 旧 | 新 | 彩度 |
|---|---|---|---|
| 亮色 | `#303a19` C 0.054 | **`#2d3e00`** C 0.086 | **+59%** |
| 暗色 | `#dce9a6` C 0.088 | **`#c6f560`** C 0.182 | **+107%** |

暗底上没有亮度天花板，所以暗色那边一步到位；亮色仍然是深橄榄，因为门要求它深。

### 三块墓碑

**一、这一项曾经戴着一块 `brand-wash` 的底。** 撤底块是对的——**该变的是图标，不是图标的背景**。

**二、撤底块时连绿一起撤了。** 理由是量了 `lq3` #93b04d 当字形墨：`side` 上 **2.05**，低于图形要求的 3.0，结论就跳到了「绿能当盘子、当不了记号」。真正的问题不在绿，在**亮度**。

**三、试过「几乎同重、只跳色相」。** 撞两条门（实心块地板 2.57 < 3.0；余量 −2.2 < +2.0）。记在这里，是为了下一个想到同一个主意的人不必再算一遍。

**指过去和打开分在两条通道上**：被指着画地，打开着画字形。所以两者不会被认错，也不必去打优先级的架。

## 用

```jsx
<Rail me items={[
  { name: 'sessions', label: '会话', on: true },
  { name: 'quota', label: '额度', badge: 3 },
  { name: 'more', label: '更多', pushDown: true },
]} />
```

消费方负责：哪一项是 `on`、徽标数字、每一项的 `label`（字形是 `aria-hidden`，可达性全靠它）。

## Do / Don't

- **竖栏的空白处拖窗口**，列表的不拖（D3）。
- 徽标 `badge` 只给真正在等人的计数；「有更新」这种不给。
- 「…」直接打开设置页，不弹菜单。
- 一个字形只代表一个落地页。`devices` 已经给了机器，网络页就得用 `network`——一个字形对应两处，就多出一个「按了才知道是哪个」的地方。
- 别拿底色表示打开。这条已经试过一次并且撤掉了——绿回到了字形上，不是回到地上。

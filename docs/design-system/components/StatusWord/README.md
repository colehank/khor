# StatusWord

六个词：**等你 · 失败 · 中断 · 完成 · 忙碌 · 空闲**。一个点加一个词，`caption` 11。

**色相说的是哪个词，亮度只说一件事：它是不是在叫你。** 四个要你回头的词（等你、失败、中断、完成）比两个安静的词（忙碌、空闲）深 8 个 L\*——亮色 8.2，暗色 8.4。**组内的先后是算出来的，不是设计出来的**：四个之间只差 0.5–1.4，按这份系统自己的标准（不并排看的两个样本要差 1 以上才分得出）根本看不见。谁要是发现「失败最响」想去修一修，那是在修一个没人看得见的东西。

色相是**教条**：等你是唯一的冷色，完成是绿，中断是琥珀，失败是红。忙碌的靛蓝坐在这套色板最空的一格（离等你 57°、离完成 92°），亮度刻意留在「不叫你」那一档。

## 用

```jsx
<StatusWord word="blocked" />
<StatusWord word="busy" dot={false} />
```

消费方负责：哪个词。文案由系统给（`Khor.WORDS`），不要自己写别的说法。

## Do / Don't

- **状态色只作墨**：一个点、一个词、一圈光晕。**永远不作行的底色**。唯一的例外是 4 px 的「一天」，那上面没有字。
- **选中后仍保留状态颜色**（2026-10-13）。点与词用同一支状态墨，头像光环保留。浅色选中灰底的两支安静墨单独补足对比度：`state-selected-busy` = `#4d57bd`（原色 OKLCH L 降 0.03，C/H 不动），`state-selected-idle` = `rgba(26,26,20,0.66)`；深色分别引用原来的 `state-busy` / `state-idle`。其余四词沿用原色。六词在选中灰底都须 ≥ 4.5，`npm run palette` 测真组件。~~选中行统一换 `ink`~~。
- 失败是深红，读起来是沉下去、已经结束的，和 `Activity::rank` 把它排到最后一致。**别为了「配合下沉」把它调淡**：那会拿一个看得清的词换一条看起来整齐的规则。
- 绿色在这套系统里只剩「完成」一个含义，不再兼任「主操作」。

# Board

右边那块板（R1）。`card` 的底、`radius-xl` 12 的角、离窗口四边 `gap-in` 8。**不描边**——深度来自 `card` 浮在 `canvas` 上，不来自边框，也不来自阴影。

页型 B 里选中的标签接进板里时，左上角变方（`joined`）。

`day` 是「一天」那条 4 px 的横条，是 **R0 和 R1 之间唯一允许存在的东西**，而且它没有文字。

## 用

```jsx
<Board joined day={[{ width: '18%', word: 'busy' }, …]}>
  {content}
</Board>
```

消费方负责：里面放什么、`joined`、以及「一天」的分段。

## Do / Don't

- 板**不要**再加一层阴影。`float` 只给菜单、搜索结果、对话框。
- 板里**不摆一排按钮**——页面级的去 R0 右端，行级的去右键菜单。
- 板里**不放第二个标题**。身份在 R0 或者标签上已经说过一次了。
- 工作区打开后，板内部分成三栏（导航 · 编辑 · 检视），栏与栏之间用 `hairline`，**不用底色**。

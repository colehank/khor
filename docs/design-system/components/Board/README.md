# Board

右边那块板（R1）。`card` 的底、`radius-xl` 12 的角、离窗口四边 `gap-in` 8。**不描边**——深度来自 `card` 浮在 `canvas` 上，不来自边框，也不来自阴影。

**板是纸，四周是框**（2026-09-30，负责人：「用灰色背景，黑色内容怎么样」「浅色也类似的去做」）。`card` 是这个主题里最极端的那一档——亮色纯白、暗色最黑——`canvas` 是它四周的灰框（亮色比纸深 7.1 L\*、暗色比纸亮 9.84 L\*）。**板上的一切都是纸**：终端（`term-bg` 就是 `card`）、对话、文件树、机器卡、额度环、浏览器；板里任何东西都不画 `canvas`——要一块「凹下去」的底用 `fill`，要淡出用 `card`。以前终端画的是 `canvas`，标签是板的灰、终端是底的黑，两者不成一体；现在选中的标签、板、终端是同一张纸（`check-palette`「终端的底 = 纸」）。

页型 B 里选中的标签接进板里时，左上角变方（`joined`）。

**例外：设置式的「…」页没有板**（2026-09-28，《骨架与三种页型》同名一节）。内容是设置组的 A 页——「…」的每一页：通用、外观、网络、安全、这台机器、诊断——设置组直接落在 `canvas` 上，像「系统设置」：组本身就是 `card`，同色的组放在同色的板上等于看不见。实现上板还在（骨架不变），页面自己的 `canvas`（`MoreFrame`）铺满它。按 2026-09-30 的规矩读，就是每一组是纸、落在框上；这是框唯一伸进板的地方。

`day` 是「一天」那条 4 px 的横条，是 **R0 和 R1 之间唯一允许存在的东西**，而且它没有文字。

## 用

```jsx
<Board joined day={[{ width: '18%', word: 'busy' }, …]}>
  {content}
</Board>
```

消费方负责：里面放什么、`joined`、以及「一天」的分段。

## Do / Don't

- 板**不要**再加一层阴影。`float` 只给菜单、搜索结果、对话框。
- 板里**不摆一排按钮**——页面级的去 R0 右端，行级的去右键菜单。
- 板里**不放第二个标题**。身份在 R0 或者标签上已经说过一次了。
- **板上的几部分是节，不是框**（2026-09-28）：一节一行小标题（`components/SectionHead`：名字用 `group` 配 `tertiary`，这一节自己的控件——比如图的 •••——在这一行右端，行高 `slot-head-h`），节与节之间一条 `hairline`。板里**不再嵌**描边的卡片、第二层底色或内缩的盒子。机器详情和额度卡的用量那半是同一个样子（一个产品，09-08 / 09-09 两条裁决）。节**里面**为了读得清的分隔（进程图和表之间那条缝，09-04「表头要明显」）不算框，照留。
- 工作区打开后，板内部分成三栏（导航 · 编辑 · 检视），栏与栏之间用 `hairline`，**不用底色**。
- **机器详情的板从一张名片开始**（2026-09-30；2026-10-01 重做，负责人：「头像也没有对齐，各类布局也很难看」）：头像、名字、「标签 · 值」两组事实（`MachineCard` 的 `Contact`，版式在《骨架与三种页型》）。照「通讯录」的一条线排：**标签的右缘 = 脸的右缘，值的左缘 = 名字的左缘，脸的中线 = 名字块的中线**——一张网格加 `subgrid`，线是构造出来的；宽时两组并排、窄时叠成一张表，行距同一个 `gap-xxs`。R0 说过的型号不再写（窄档没有 R0，写在名字下面）。名字是名片的一部分，**不是标题元素**（`<p>`，`title-md` 的字），所以它不是「第二个标题」；名片落在纸上不画框，下沿 `gap-group` 后一条 `hairline` 和表盘那一节分开。

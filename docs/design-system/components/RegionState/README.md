# RegionState

一块区域（板、板里的一栏、设置里的一组）在任何时刻正好是五种之一。样子由这一个组件给，**页面不自己拼**——那正是今天修好一页别的页不跟着好的原因。

| 状态 | 长什么样 | 绝不 |
|---|---|---|
| `loading` 从没看过 | 骨架行 / 骨架卡，底 `fill`；不到 1 秒不出转圈 | 一块空白的板 |
| `refreshing` 看过 | 上次的内容原样留着，R0 底部一条 2 px `brand` 的线 | 先清空再填 |
| `stale` 过期 / 离线 | 内容留着 + R0 右端一行 `caption`：「3 分钟前的读数」 | 板里出现横幅 |
| `empty` 空 | `EmptyState`，一句话 ≤ 一个按钮 | 插画、两个按钮 |
| `error` 出错 | 机器自己那句话放在空状态的位置 + 「重试」 | 红框、堆栈 |

两条时间线（D5）：**300 ms 之内一定看得到上次的内容或骨架；这台机器的数据 1 秒之内到。**门：造一个 `statfs` 要 10 秒的假盘，机器页仍要在 1 秒内出现卡片。

## 用

```jsx
<RegionState state={state} note={err} action="新会话">{content}</RegionState>
```

消费方负责：`state`、出错时机器自己那句话、空状态的按钮。

## Do / Don't

- **回到一页，第一帧就是上次的内容**，然后原地刷新。进、出、再进，第二次不许有空帧。
- 一个慢的数据源**只拖慢它自己那一格**。阻塞的活不许跑在异步池上。
- 骨架的形状要和真内容的形状一样（几行、多高），不然填进来的那一刻会跳。

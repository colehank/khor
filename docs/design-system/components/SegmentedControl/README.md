# SegmentedControl

从**几个固定的**里选一个，而且几个全摆在眼前。macOS 的 `NSSegmentedControl`。2026-09-28 负责人定下来，替掉新会话 sheet 里那几排自己画的灰「药丸」。

样子：一条 `fill` 的槽，`radius-sm` 6，`ctl-md` 28 高；每一段是一颗按钮，字 `body` 配 `ink`，左右 `gap-row` 12。**选中的那一段是槽里的一块面**：`segment` 的底、`radius-xs` 4、`ctl-sm` 22 高，四边离槽 3，`knob` 那一档阴影托起来——和开关的钮是一家。两段都没选中时，中间一根 `hairline` 竖线（高 `gap-base` 16）；挨着选中那一段的线不画，那块面自己就是边。

```
目标机器     [ gate 本机                   ⌃⌄ ]
会话类型     │ 留言 │▓智能体▓│ shell │
使用的智能体 │▓claude▓│ codex │   添加…
打开方式     │▓对话▓│ 终端 │
```

**为什么选中那一段不用 `card`**：暗色里 `card` 比落在 sheet 上的槽还暗，选中的那一段会读成一个坑。所以它有自己的 token `segment`：亮色是白（比槽高 5.8 L\*），暗色是一层更亮的淡底（在 sheet 上比槽高 13.6 L\*）；上面的 `ink` 亮 14.87 / 暗 6.40，`check-palette` 守 4.5 和「比槽亮」。

## 什么时候用它，什么时候用弹出按钮

| 选项 | 用 |
|---|---|
| **≤ 4 个，而且不会长**（会话类型、打开方式、计费/订阅、24h 日志/统计） | SegmentedControl |
| **会长的一串**（机器、目录、服务商、注册过的 agent） | PopupButton（系统菜单） |
| 平常很短、但是开放的（使用的智能体：khor 自己的两个 + 你接进来的） | 在 4 个以内画分段，第五个接进来的那天同一行换成弹出按钮；每个选项的锚点两边一样 |
| 只有是/否 | Switch |
| 多选 | 菜单里的勾选项，不是这个 |

## 键盘与无障碍

它是 `radiogroup`，每一段是 `radio`。**只有一个 Tab 停点**（选中的那一段）；← → ↑ ↓ 换选中并把焦点带过去，Home / End 到两头；灰掉的那一段被跳过。组的名字（`aria-label`）是它左边那一行的标签。

热区：按钮本身是热区（`--hit`，鼠标时就是 `ctl-md`，手指时涨到 `touch` 44），那块面画在按钮里面——和开关的做法一样，样子不变。

## 用

```jsx
<SegmentedControl
  label="会话类型"
  value={kind}
  onChange={setKind}
  options={[
    { key: 'tell', label: '留言' },
    { key: 'agent', label: '智能体' },
    { key: 'shell', label: 'shell' },
  ]}
/>
```

实现：`apps/gui/src/components/ui/segmented-control.tsx`（`SEGMENTS_MAX` = 4）。机器卡里「24h 日志 / 24h 统计」那一对不是 React，`src/day/day.css` 的 `.sw` 用同一批 token 画同一个样子。

消费方负责：标签、当前值、选项、变化回调；每一段可以带自己的锚点（`mark`）。

## Do / Don't

- **一段是一个选择，别的都不是。** 「添加…」这种会打开别的东西的，**放在控件后面**，是一颗普通按钮（`plain`，带省略号），不是第四段：做成一段，它会被念成一个单选项、方向键会停在它上面、看起来像又一个名字。
- 段里只放一两个词。要解释的放在行的 `note` 里，不放进段。
- 等宽不是规则：每一段跟着自己的字宽。太挤时段会截断（`title` 给出全名），先截最长的那一段。
- **不要**给选中那一段换品牌色。它是一块面，不是强调——橄榄绿只给开关、焦点和那一个主按钮。
- **不要**把选中的字加粗或换墨来表示选中；面已经说了。所有段的字都是 `ink`。
- 选项超过 4 个或者会长，就不是它了——换弹出按钮，别让一行分段折成两行。

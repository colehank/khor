# 区域状态与浮层

## 区域状态——每种状态全 app 一个样子

一块区域（板、板里的一栏、设置里的一组）在任何时刻正好是下面五种之一。样子由 `RegionState` 一个组件给出，页面不自己拼。

| 状态 | 长什么样 | 绝不 |
|---|---|---|
| **加载中，从没看过** | 骨架行 / 骨架卡，底色 `fill`；不到 1 秒不出转圈 | 一块空白的板 |
| **加载中，看过** | 上次的内容原样留着；R0 底部一条 2 px `brand` 的进度条表示正在刷新 | 先清空再填 |
| **过期 / 离线** | 上次的内容 + R0 右端一行 `caption`：「3 分钟前的读数」 | 板里出现一条横幅 |
| **空** | 空状态组件（一句话，最多一个按钮）居中在 R1 | 插画、两个按钮 |
| **出错** | 机器自己那句话放在空状态的位置，配一个「重试」 | 红框、堆栈 |

两条时间线（D5）：**300 ms 之内一定看得到上次的内容或者骨架；这台机器的数据 1 秒之内到。**

**「上次的内容」是一行上画出来的全部**，不只是行本身：别的机器答的那几样——排序靠的时间、角标、分支——也是上次的内容，离开这一页不许丢。2026-09-29 工作区栏只留了行，每次回来都先画成一排文件夹、按路径排，答案回来再换角标、再重排（负责人：「每次新进入工作区，都要从原始的工作区顺序到置顶设置好的顺序。角标也从普通到git」）。一页自己取数据时，把它答过的放在组件外面（模块里，或者 App 里），回来先画它，再重新问。

## 浮层——什么事用哪一种

| 要干的事 | 用 | 不用 |
|---|---|---|
| 从几个里选一个 | 系统的弹出菜单 | 自己画的下拉 |
| 对某一行下手 | 系统的右键菜单（第一项置顶，最后一项删除，自成一组） | 行里内嵌一排按钮 |
| 确认一件毁掉东西的事 | 对话框 380 宽，能加「不再提醒」的就加 | `alert()` |
| 带表单的新建 / 导入 / 加入 / 登记 | 居中的对话框 + 遮罩，宽一档（32rem），按在外面不关（2026-09-30，负责人：「是要来一个弹窗…类似机器页点 ＋ 后的邀请设备弹窗」） | 从 R0 落下的面板（⚠️ 墓碑：09-28 到 09-30 的 sheet，负责人读成「从标题下长出来的奇怪东西」） |
| 搜索结果 | 垂在搜索框下面，不加遮罩 | 居中的命令面板 |
| 一次性的回报（已置顶、已复制） | 底部状态栏，2 秒 | 盖在内容上的 toast |
| 一个读数的详情（手机没有悬停，按一下看） | 挂在那一点下面的浮层（`ui/popover`，Radix，非模态：不锁焦点，点外面、Esc 收起，焦点回到按的那一处） | 居中的对话框；只在指针停着时才有的提示 |

浮层只有一档阴影 `float`，外加 1 px `hairline`，底一律是 `popover`，圆角 `radius-lg`（对话框、菜单、搜索结果、框下的补全、斜杠命令、终端的查找条和「到底部」、文件底部的提示、图的设置面板、「一天」按下去的那块浮层（`ui/popover`，2026-09-29）都是；2026-09-28 之前后几样各穿各的 `shadow-sm/md/lg`、`card` 或 `canvas`、`rounded-md`）。例外只有两处，照实记下：提示（Tooltip，连「一天」的读数）是 `radius-sm`；文件里对比旧行的那条横带横跨整栏，没有角。（第三处是挂在 R0 下沿、只圆下两角的 sheet，2026-09-30 撤了。）`check-face` 4J (c) 读每一个文件，4I 在暗色里量真的几种浮层的阴影和圆角。**暗色里 `popover` 比 `card` 亮一档**：黑影落在近黑的板上看不见，同值的浮层会平贴在板上（2026-09-28，`check-palette` 要它至少高 4 L\*，`check-face` 4I 量真的四种浮层）。板、设置组、标签页都**不是**浮层，它们靠 `card` 落在 `canvas` 上获得深度。

# 骨架与三种页型

窗口只有一副骨架。六个区域，每个区域的尺寸、谁能拖动窗口、里面允许放什么，都在这里定死；页面只决定放进去的是什么。

```
┌──────────── L  左块 ──────────────────┬──────────────── R ────────────────┐
│ L0  ● ● ●  [ 搜索              ⌘K ] + │ R0  标签条  ·  或  ‹ ›  页面标题    │  ← 两条都是 48
├──────┬────────────────────────────────┤ ┌────────────────────────────────┐ │
│ L1   │ L2 列表                         │ │ R1 板                           │ │
│ 竖栏 │ （列表行、分组标题）             │ │ （页面内容）                     │ │
│ 64   │ 宽度归 L 所有                    ║ │                                 │ │
└──────┴────────────────────────────────╨─┴────────────────────────────────┘─┘
                                          ║ = 唯一一道宽度把手
```

| 区域 | 尺寸来自 | 放什么 | 空白处能拖窗口 |
|---|---|---|---|
| **L** 左块 | `rail-w` + 列表宽，**只存一处，存在 L 上** | L0、L1、L2 | — |
| **L0** 第一行 | `pane-head` 48 | 三颗窗口按钮（macOS）· 搜索框 · ＋ | 能 |
| **L1** 竖栏 | `rail-w` 64 | 五个落地页、更多、这台机器；打开的那一项变**图标**（墨换成 `rail-on-ink` 深橄榄绿、实心块填到 1.0），不变背景 | 能 |
| **L2** 列表 | 跟随 L | 列表行、分组标题 | **不能**（D3） |
| **R0** 工具栏 | `pane-head` 48，**每一页都有** | 标签条——或者后退/前进 + 页面标题（D2） | 能 |
| **R1** 板 | 四边 `gap-in` 8，圆角 `radius-xl` | 页面 | 不能 |

三条不许破的：

- **拖动区域由外壳声明一次**，写在 L0、L1、R0 上。里面的控件由 tauri 自己的规则排除。**组件永远不自己标拖动区域**。
- **宽度只有一个主人。** L 右缘那道缝是唯一的把手；L0 跟着它走，搜索框在溢出之前先压成一枚放大镜。任何区域不许有第二个宽度来源。
- **R0 和 R1 之间不许塞东西。** 不加副标题行，不加状态句。会话页那条 4 px 的「一天」是唯一的例外，而且它没有文字。

**平台差异。** macOS：三颗窗口按钮在 L0，左块用侧边栏材质。Windows：最小化/最大化/关闭在 R0 右端，L0 从搜索框开始。Linux：系统装饰在窗口之上，L0 从搜索框开始。网页端：同 Linux，且没有装饰。非 macOS 一律没有材质，左块用 `side` 实色。

## 三种页型——每个落地页正好是其中一种

今天右边有六种各自拼的做法（会话用 `Tabs` 或 `Region`，机器用 `Region`，额度和浏览各写各的，更多用 `Region`，打开的工作区是裸的三栏）。这就是修好一页别的页不跟着好的原因。从这里开始只有三种页型，每种一个组件，落地页声明自己是哪一种（D7）。

| 页型 | 心里的模型 | L2 列表 | R0 工具栏 | R1 板 | 用在 |
|---|---|---|---|---|---|
| **A 详情** | 选一个，看它 | 全部条目，一个选中 | ‹ ›（选择历史）· 标题 · 页面按钮在右端 | 选中那一项；没选中时是总览 | 机器、额度、更多 |
| **B 标签** | 开几个，来回切 | 全部条目，最前面那个标签对应的行选中 | 标签条 · ＋ | 最前面那个标签；没有标签时是总览 | 会话 |
| **C 文档** | 这一行本身就是活的页面 | 全部文档，一个选中 | ‹ › ⟳ · 地址/标题 · 页面按钮 | 那个文档 | 浏览 |

**工作区是 B 装在 R1 里**（D8）：工作区打开后，板内部分成三栏——导航（文件树）· 编辑（B：文件标签）· 检视（它的会话）。每一栏自己有一条 48 高的头，和 R0 对齐；栏与栏之间用发丝线分，**不用底色分**。

### 三种都守的规矩

- **身份只出现在一个地方**：R0 的标题（A、C）或者标签（B）。板里不许再有第二个标题。
- **每个落地页有一个总览**，在没选中（A）或没有标签（B）时显示：会话 →「等你的事」+ 机器；机器 → 那张图；额度 → 所有账户的环；更多 → 通用。总览用同一种页型的 R0，标题是落地页自己的名字。
- **选择和标签（B）**：按一行 = 打开或切到它的标签；关标签**不删行**；删行**关它的标签**。列表的选中项永远等于最前面那个标签。
- **历史（A、C）**：‹ › 走的是在这个落地页里做过的选择，和「系统设置」一样。无处可去时这对按钮不出现。
- **页面级按钮**（新会话、机器那三个按钮、注册账户）放 R0 右端（D9）；**行的动作放右键菜单**。不许两边都有，不许在板里摆一排按钮。
- **创建类的表单**（新会话、导入、注册账户）是从 R0 落下来的面板（macOS sheet），不是居中的模态窗（D10）。
- **窄档**（< `narrow` 760）：每一种页型都变成「列表一屏 ⇄ 详情一屏」，R0 左上角是返回；B 在 R0 右端多一个标签计数按钮。竖栏变成底部栏，板铺满屏幕，不留边距也不留圆角。

# 行为与门

每一行后面都跟着一道能变红的检查。**没有门的那一行不算规则**，只算愿望。

**什么配门（2026-09-25 起）。** 门只给两类东西：机器量得准、人眼看不出的（token 值、对比度、字号档、像素与色值字面量、图标家族、首帧颜色、拖动区域、慢源时限）；以及出过事的。布局摆放——按钮在不在 R0、sheet 离顶多远、某页有没有某一行——不再写成 `check-face` 断言，放进每轮末「真 app 走一遍」的验收清单，由负责人对着看。

**先红后绿只用于修 bug**：先写一个在旧代码上变红的门，再修到绿。新功能不必先证明旧版会红。

| 规则 | 门（先看到红） |
|---|---|
| 一页在 **300 ms** 内显示上次的内容或它的骨架；这台机器的数据 **1 秒**内到（D5） | 造一个 `statfs` 要 10 秒的假盘 → 机器页仍在 1 秒内出现卡片 |
| 回到一页，第一帧就是上次的内容，然后原地刷新 | 进、出、再进：第二次没有空帧；**工作区栏**另有 `check-face` 4f·back：扣住每一行的三个问题（时间、是不是仓库、git）再回来，第一眼的顺序、角标、分支和离开时一字不差（2026-09-29，旧代码上先红：回来时角标全是文件夹、分支是空的）；重开 app 也先画上次记下的顺序与角标（`khor.ws-known`） |
| 一个慢的数据源只拖慢它自己那一格；阻塞的活不许跑在异步池上 | 单测：存在一个慢源时，其余请求的延迟不变 |
| 每一页的 L0、L1、R0 空白处都能拖窗口 | 走一遍每个页面，按遍每个空白点，用 tauri 自己的算法判定 |
| 拖那道缝时，L、它的底、L0 一起动 | 拖到三个宽度；四个宽度值一致 |
| R0 和 R1 之间除了「一天」什么都没有 | 沿用第十四轮的门 |
| 选中行是灰块、字一律满值 `ink` | `check-palette` 把选中行三种文字对它的底一起量，任何一个低于 4.5 变红；底是 `brand-strong` 也变红 |
| 「…」页的设置行：每种行画出来的控件右缘在同一条线上；一行的行一样高；组名不复述页名；依附于锁的两行在锁关着时不可用、没有 PIN 时开关先要 PIN | `check-face` 4I：六页逐行量右缘和行高、比组名与 `aria-label`，安全页开关前后读两行的 `disabled`，撤掉 PIN 后按开关必须弹出 PIN 窗口（2026-09-28，旧代码上先红过） |
| 浮起来的东西在暗色里比板亮一档，上面的字仍过 4.5 | `check-palette`：暗色 `popover` 至少比 `card` 高 4 L\*，`ink` / `secondary` / `destructive` 在它上面 ≥ 4.5，打开的对话框穿的是 `popover`；`check-face` 4I：暗色里 sheet、对话框、右键菜单、搜索结果的底都比板高 4 L\*，2026-09-30 起也比框（`[data-main]`）高 4 L\* |
| 竖栏未打开的字形，描边不低于 4.7 / 5.5，实心块不低于 3.0 | `check-rail` 的 `LINE_FLOOR` 与 `FLOOR` |
| 竖栏打开的字形是品牌色（彩度 ≥ 0.08）、未打开的是灰（< 0.03），打开的描边 ≥ 3.0，**静止和被指着时都要过** | `check-rail` 的 `OPEN_CHROMA` / `REST_CHROMA` / `FLOOR`，两种底各量一次 |
| 实心块永远比描边浅 | `check-rail`：`body < line`，否则「两种密度」这个主张就被删掉了 |
| 界面里不出现颜色字面量，一律引用 token 名 | `check-px.mjs` / `check-palette.mjs`：一个散落的像素值或色值就是构建错误 |
| 只有一套图标字形 | `check-icons.mjs`：从外部图标包 import 就变红，并且报出是哪个包 |
| 字号只从 14 个 type style 里取 | `check-type.mjs` |
| `tokens.css` 与这份系统的值一致 | `check-boot`：改一个值时两处必须在同一个 commit 里 |
| **手机不托管，也不说它托管**（docs/IOS.md 第二步）：一台机器能不能托管是它自己在设备表里说的一个事实（`hosts`，手机的构建答否）；要托管机器的入口都读它——那台不能托管就不画开会话、VS Code、进程表，本机是手机就不画借网、VS Code、钩子、拉过来、导入里的问一次、网页脸的钥匙、设置里的打开、锁屏的系统验证；新会话默认第一台能托管的机器，挑到手机只剩留言；绕过界面来问的，节点在登记前用语料库的话拒绝；不能托管的节点不找 tmux、不读进程表 | `check-face` 第 18 节（`FACE_ONLY=phone`）：电脑看手机、本机是手机两臂，每条都有同页对照，并数请求（`code_here`、`hooks_state`、`web_key`、导入时的 `agents` 一次都不发）；节点单测三条（自己的行、各个门在登记前拒、别台照表先拒不拨号、手机的自检）；`tests/no_host.rs`：`KHOR_TMUX` 指向一个记账的假 tmux，不能托管的节点三轮列表加采样一次不起、不读进程表，电脑做对照。Rust 的几条用变异看过红（发现不关死、门不拒、不写行）；面门这一节没在旧前端上看到红（换回旧文件被权限系统拦下），见 handoff 001 ios2 那一节 |

## 真 app 验收清单：布局那几条

门不量的摆放放在这里，每轮末负责人在真的 app 里对着看（网页端截图不算）。新加的写在最上面，看过、稳了的留着当回归清单。

**2026-10-08 药丸左右滑、暗色遮罩**（UX-49，ux-t 车道）。真 iPhone：

- **暗色遮罩**：暗色主题，终端里有字时点药丸开附栏、点标签圆钮开标签面板：后面的终端整块变暗，像它重连时那样，不是一层灰纱；面板的黑底靠上沿那条灰线站出来。亮色照旧是深灰。
- **成环**：开两个会话，在药丸上往左滑一下、再往左滑一下：两次都换到另一个；往右滑也一样。开三个，在最后一个上往左滑是第一个，在第一个上往右滑是最后一个。
- **一个标签**：只开一个会话，左右拖药丸：只挪一点、越拉越紧，松手弹回原位，不震。
- **一开拖就看见**：拖动刚开始，下一枚的头像和名字就从药丸右沿露出来（往右拖时上一枚从左沿露出来），中间没有一段空白；当前那枚名字很长时也一样。
- **过线有感觉**：慢慢往左拖，过了大约药丸宽度的四成，手机轻震一下，进来的那枚变实、当前那枚变淡；拖回去再震一下，又反过来；在线内松手弹回、在线外松手换过去。
- **换过去时滑一下**：从右边进来的那枚松手后在约 0.2 秒里从右边滑到靠左的位置；没换过去时原路收回，不滑。
- **快甩**：在药丸上快速一甩，哪怕只甩了一点点，也换过去。
- **拖到一半停**：名字很长的那枚，拖到一半停住再松手：回到原位，头像完整地在药丸左端，不会有半张脸在药丸外。拖到一半时从屏幕底边往上划回主屏、或来个电话，回来时药丸也是停好的一枚。
- **浏览器的原生甲板**：浏览器开两三页，在药丸上左右轻扫：同样成环（最后一页往左是第一页）。

**2026-10-07 存储**（STORE-BRIEF 第一阶段，store-b 车道）。Mac 上的 app 和真 iPhone 各一：

- **改位置**：更改… 选一个目录，路径马上换成它，出现「恢复默认」；给另一台改，那台在线时几秒内路径换过去，离线时写「…同步后生效」，那台连上后自己换。恢复默认回到 `~/khor-drop`。

**2026-10-01 终端滚轮与输入法**（负责人：「初次进入一个 tmux 会话的标签，滚鼠标滚轮页面没有变化；把窗口缩放一下就能滚了」「『(』『"』这类符号要按两次才上屏」）。装机后走；已经在跑的宿主是旧代码，要等它的 tmux 标签新起一个宿主：

- 额度卡详情：用量那半同样没有框，「token 用量」「模型」两节，••• 在各自标题行右端。
- 会话总览：「待处理」那一行右边没有「新会话…」，R0 右端有。

## 选字与手（2026-09-28）

**界面的字不是文字。** 访达的侧边栏拖不出蓝色，双击行名是打开这一行，不是选中一个词。所以页面默认 `user-select: none`（`app.css`，在 `@layer base` 里，工具类还能盖过它），**能选的地方只用一种写法标：`data-selectable`**，标在读的那块面上：

- 对话那一栏（`ChatView` 的 `data-chat-column`）、所有 Markdown（`data-md`）、文件与 diff 与代码（行号自己带 `select-none`，不跟着选）、机器之间的消息；
- 人会抄走的值：「…」页事实行的值（id、版本、路径，`MoreFact`）、网页端的钥匙、中继地址、诊断每一条的原话和出错那一句、diff 读不出来的那一句。
- 输入框、多行框、`contenteditable` **永远能选**——WebKit 里一个 `none` 的祖先会让输入框打不进字。
- 终端是 xterm 自己画的，它在自己的画布上选，不用标。
- 读的面里的按钮仍是界面（复制按钮上的字不是段落的一部分），正文里的链接除外——那是段落自己的字。

**手指形光标只属于正文里的链接。** macOS 的控件、行、菜单、标签、开关、图表上的点都是箭头；手指只在一段字里的链接上出现。今天留着手的两处：Markdown 的链接（`data-md-link`）和对话里的路径（`PathLink`，`data-link`）。别的地方写 `cursor-pointer` 就是 `check-face` 第 3 节的红。**灰掉的控件上也是箭头**：AppKit 不在不可用的控件上换光标，灰已经说了「不能」；shadcn 带来的 `disabled:cursor-not-allowed`（开关、输入框）2026-09-28 拿掉了，§11b 读 computed 也读源码。

**右键。** WKWebView 在任何地方右键都会弹它自己的菜单（重新载入、检查元素）；Mac app 的侧边栏上没有这种菜单。`lib/shortcuts` 在窗口上（冒泡阶段，让 Radix 的行菜单先拿到事件）把它挡掉，**只放过**输入框里和选中的字上——那里系统的菜单有用（剪切、拷贝、粘贴、查询）。行自己的右键菜单照旧。网页端同一条规矩。

整张表在 `apps/gui/src/lib/shortcuts.ts` 一处，菜单栏（`src-tauri/src/menu.rs`）用同样的名字，两条路走进同一个函数。

- **⌘ 在 Mac 以外是 Ctrl。在 Mac 上 ⌃ 不是 ⌘**：⌃W ⌃K ⌃L 是输入框和终端自己的键（删一个词、删到行尾、清屏）。⚠️ 以前是 `metaKey || ctrlKey`，终端里按 ⌃L 清屏会把 app 锁上。
- **⌘W 没有标签可关时什么都不做**，菜单上「关闭标签页」变灰。它**不是**「关窗口」——默认菜单把 ⌘W 给了关窗口，而关掉 khor 唯一的窗口就是退出 khor，khor 又是这台机器在网里的节点：多按一下关标签，网里就少了一台机器。要关窗口是 ⇧⌘W。
- **输入框里照样管用**，像 Safari 地址栏里的 ⌘W：这张表里每个键都带 ⌘（或 ⌃⇥），没有一个是字。⌘C ⌘V ⌘A ⌘Z 是编辑菜单的，不在这张表里。
- **终端让出 ⌃⇥**：Terminal.app 和 iTerm 都拿它换标签，shell 也分不出 ⌃⇥ 和 ⇥。终端要的别的键都不带 ⌘。
- **sheet 和对话框开着时，除了 ⌘L 都不应**：sheet 是窗口在等的一个问题，Esc 或它自己的按钮回答它。锁着时什么都不应。
- **网页端把浏览器的键留给浏览器**：⌘W ⇧⌘W ⌘N ⌘1–⌘5 ⌃⇥ ⌃⇧⇥ ⇧⌘] ⇧⌘[ 是开、关、走浏览器自己的标签，页面拿走它们就是从人手里拿走。**不设替代键**——能想到的每一种写法都是某个浏览器或系统的（⌥⌘←→ 是 Chrome 的标签、⌃PgDn 是 Firefox 的、⌥1 在 Mac 上是一个字、⌃1 是桌面空间）；竖栏和标签条一下就到。
- **一次按键只跑一次。** Mac 上一个带 ⌘ 的键先到页面，页面没 `preventDefault` 的才会被 WKWebView 再交给菜单栏。所以页面跑了的键一律 prevent，菜单的快捷键只在页面根本没看到这个键的地方起作用：浏览器标签自己的网页里、编辑器窗口里。编辑器窗口在前时，⌘W 和 ⇧⌘W 关的是它自己；别的项先把主窗口叫到前面再做。
- ⌃⇥ 在菜单上只是写着给人看：muda 把 Tab 的键写成「⇥」这个字，没有哪个键按出来是它，所以永远由页面接。

## 菜单栏（2026-09-28，只有 Mac）

**khor**：关于 khor · 设置… ⌘, · 锁定 ⌘L · 服务 · 隐藏 khor · 隐藏其他 · 全部显示 · 退出 khor ⌘Q
**文件**：新建… ⌘N（换成那颗「+」的名字）· 新建标签页 ⌘T · 导入会话… · 关闭标签页 ⌘W · 关闭窗口 ⇧⌘W
**编辑**：撤销 · 重做 · 剪切 · 拷贝 · 粘贴 · 全选（**必须有**：没有它们，WKWebView 的输入框里 ⌘C ⌘V 不起作用）· 查找… ⌘F
**显示**：五个落地页 ⌘1 … ⌘5（照图标条的顺序）· 隐藏边栏 ⌃⌘S · 搜索 ⌘K · 刷新终端 ⌘R · 跳到上一条 / 下一条命令 ⌘↑ / ⌘↓ · 历史命令… ⇧⌘; · 进入全屏幕
**窗口**：最小化 · 缩放 · 显示上一个 / 下一个标签页 ⌃⇧⇥ / ⌃⇥ · 前置全部窗口 · 窗口列表（AppKit 自己填）

没有「帮助」：还没有东西可放，一个空菜单教人别打开菜单。字全部来自目录的 `[menu]` 一节（和竖栏的五个名字），用这台机器现在说的语言；设置里换语言、或在终端 `khor config set lang` 之后窗口回到前面，菜单重搭。Windows 和 Linux 不搭菜单栏——那里的菜单栏会变成窗口里的一行，骨架里没有这一行；那边只有页面的键盘这一条路。

**名字，和 AppKit 自己加的项（2026-09-28）。** app 是以裸二进制跑的（`target/local/khor-gui`，外面没有 `.app`）。一个没有 Info.plist 的进程，AppKit 拿进程名当 app 菜单的粗体标题——读出来是「khor-gui」，不管 `menu.rs` 给那个子菜单起什么名；它自己往编辑、窗口里加的项（自动填充 · 开始听写… · 表情与符号；全部最小化 · 全部缩放 · 填充 · 居中 · 移动与调整大小 · 全屏幕平铺 · 从组中移除窗口 · 排在前面）说英文，因为进程没声明任何语言。现在二进制里嵌着 `src-tauri/Info.plist`（`src/main.rs`，`__TEXT,__info_plist` 段）：`CFBundleName` = khor，声明 zh-Hans 与 en、开发语言 en。**不写 `CFBundleAllowMixedLocalizations`**：AppKit 只在这两种里挑，第三种语言的桌面上它说英文，和 khor 自己的字一样（「非 zh* 一律英文」）。

- **不写 `CFBundleIdentifier`，不改可执行文件的名字，不调 `setProcessName`。** WebKit、CFNetwork、defaults 给自己的目录起名用 `bundleIdentifier`，没有才用进程名。页面的 localStorage 今天在 `~/Library/WebKit/khor-gui/WebsiteData/`（设了 `KHOR_HOME` 的在 `…/khor-gui/WebsiteDataStore/<uuid>/`），缓存在 `~/Library/Caches/khor-gui/`，cookie 在 `~/Library/HTTPStorages/khor-gui.binarycookies`，偏好在 `~/Library/Preferences/khor-gui.plist`。加一个标识符，下次启动就是一个空的页面 store——在临时二进制上量过，数据落进以标识符命名的新目录；`setProcessName` 改不了粗体标题，却把 WebKit 的目录改成了新名字（也量过）。哪天真要打成 `.app`，先迁这几处。
- **AppKit 的项跟 khor 的语言。** 系统的第一语言挑出来的和 khor 正在说的不同时（中文 Mac 上设成英文的 khor），`menu::speak_at_launch` 在启动时把 khor 的语言放到这个进程 `AppleLanguages` 的最前面——**只放在内存里的参数域**，不写任何偏好文件：app 的偏好域以进程名命名，本机每个 khor-gui（负责人的、原生门的）都会读到。这和 macOS 自己的「按应用设语言」是同一个开关，所以管到的也一样：系统面板（选文件、Touch ID）、webview 的 `navigator.language`——浏览标签页先向网站要 khor 的语言，页面的 `auto` 也落到 Rust 那半边选的那种。两者本来一致时什么都不动。
- **只在启动时。** CoreFoundation 第一次被问就把一个 bundle 的语言定下来，之后不再改（量过：进程里换语言再重搭菜单，AppKit 的项还是原来那种；私有的清缓存函数也不行）。所以运行中换语言，khor 自己的项立刻跟上，**AppKit 的项下次启动跟上**。

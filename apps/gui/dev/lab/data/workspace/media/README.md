# Browser and media fixture

The HTML page uses relative CSS, JavaScript modules, imported modules, JSON, video and audio. These are finite Lab records, rendered by the production file components. The static frontend Lab verifies browser interaction; authenticated remote reads, byte ranges and cancellation are separate native checks.

`clip.mp4` and `audio.wav` were generated for Khor with FFmpeg's `testsrc2` and `sine` sources in GitHub Actions run 42994611398. They contain no third-party recordings. Five seconds of H.264 test video and PCM test audio are used only as test data.

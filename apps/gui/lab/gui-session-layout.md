## 输入区统一实验

2026-10-23 用户要求先做 Lab 查看，尚未批准合并。默认采用统一输入区，勾选「对比原来的输入区」恢复原来的模型行、权限与信息入口。顶部甲板位置可独立对比。

- 顶部模型短名称打开会话设置。ACP 沿用宿主提供的模型、思考与权限选项；自动执行状态留在顶部入口，完整模型 ID 收在详情。Khor 通过执行节点的 Pi SDK 查询模型、思考与自动压缩选项，选项校验后立即保存；不从示例清单推断真实能力。
- 底部统一「＋、发消息…、发送／停止」。添加菜单只含附件操作；没有附件时不显示上传目录。添加后显示短目的地、附件和移除操作。上传目的地也能在选文件前从添加菜单更改。
- 「附带示例文件」通过正式文件输入事件加入一个内存中的示例 Markdown。预览 bridge 消耗并丢弃上传字节，不写文件；模型、权限、发送和停止也只操作内存示例。
- 顶部设置与「＋」直接复用 App「…」的 `DropdownMenu`、`MenuViewport`，共用玻璃材质、圆角、菜单行和滚动上限。选择模型／思考／权限时在同一菜单里切换选项列表，支持「返回」、方向键与 Esc；不在菜单内堆表单控件。「上传位置」先关闭菜单，再打开持久挂载的公共目录选择器。
- Khor 菜单明确显示「执行权限：逐项确认」。实际执行由 Rust MCP 边界审批：读取直接执行，修改操作等待用户允许。目前是固定策略，没有可切换的自动授权档位。选择 Khor 场景后勾选「演示 Khor 待审批」，可查看正式审批组件的批准／拒绝／停止流程；示例不会执行工具。

## 底部组合操作区实验

- `SessionScreen` 的 `combinedDock` 只由 Lab 注入，默认关闭；样式仅从 Lab 加载。输入框增高向上长，下层药丸位置不变，组合版阅读历史时不折叠导航。键盘模拟升起时整组贴着可见视口；长草稿有高度上限，横屏留出内容。宽屏仍保留正式的顶部标签布局。
- 设置收进下层右侧「…」，菜单在面板上方展开。附件菜单与目录选择沿用公共组件。上滑药丸使用公共 `TabSheet`，选中后返回当前对话，不再停在附栏里。
- Lab 的文字草稿按会话暂存在页面内存；发送清空，刷新清空。控制面板切换布局／主题／键盘时会带上当前文字和选择范围，方便对比。附件不做新的跨会话缓存，也不写浏览器持久存储。
- 原生 iOS 的键盘动画和切换时的焦点仍需真机验证；当前验收针对隔离的浏览器预览。


## 模型栏与底部头像实验

- 当前默认 `deck=compose`，旧方案仍在「布局」选择器里。左上返回无底，模型短名、当前思考强度和下箭头以文字显示，点击使用 App 的公共菜单配置；右上只有新建，使用方框与斜笔图标，接入正式新建会话页。页头不显示当前会话标题。
- 输入栏顺序是「会话头像、＋、发消息…、发送／停止」。头像不再单独套玻璃。文字换行或开始折行后独占整行并向上长；控制按钮守住底边，仍是一块玻璃。宽屏沿用原顶部标签和公共输入布局，实时切换尺寸时也保留草稿。
- 点击底部头像打开公共标签页列表。长按 350 ms 展开透明外弧，最多五个邻近会话；头像右侧显示标题。背后正文使用公共遮罩并模糊，避免标题与正文叠字。滑动只预览，松手提交；回到原头像、Esc、指针取消、第二触点、失焦或窗口变化会取消。斜上推到右侧「全部标签页」目标，松手打开完整列表。
- 思考强度通过 ACP `thought_level` 分类识别，Khor 由 Pi SDK 会话选项获取；未提供时只展示模型。Khor 加载后读取一次设置，打开菜单时再刷新。没有伪造统一的可选能力。权限和上下文仍在会话设置菜单里。

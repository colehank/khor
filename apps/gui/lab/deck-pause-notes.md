# 药丸停留自动 Lab

启动：在 `apps/gui` 运行 `./node_modules/.bin/vite --config lab/deck-pause.vite.ts`，打开 `http://localhost:1437/lab/deck-scrub.html`。

正式 App 与 Lab 共用 `src/lib/deck-scrub.ts`。`lab/deck-scrub-pause-model.ts` 仅注入调参入口，参数按每次接触取快照，不维护第二份交互逻辑；正式 App 使用固定默认值，不读取浏览器的 Lab 设置。

## 已确认的交互

- 初始触点附近持续暂停；最近一次明确滑动决定方向。
- 长按 320 ms 进入探索；停手约 200 ms 后就近停靠，完整停靠后再等 1200 ms 启动自动。
- 自动中反向回上一候选；重新停靠、等待，自动速度恢复慢速。途中再次换向，连续改向新目标且不累计跳项。
- 轻微抖动不重置等待或反复刹停；暂停区有最小范围和进入／退出滞回。
- 松手锁定一次目标；迟到移动和重复松手不改目标，取消不打开中间内容。

这些是负责人试用确认的产品参数，不宣称普遍人因标准。

## 调参

自动启动等待（300–3000 ms）和停靠触发延迟（40–500 ms）在页面上可直接输入或拖动；更多参数含长按时间、反向距离、静止容差、暂停区倍率、跟手灵敏度、慢速／最快逐项停留及动效时长。默认值与正式 App 一致：1200 / 200 ms。

参数写入独立的 `khor.lab.deck-tuning.v1`，刷新保留，可恢复默认或复制 JSON。页面验收暂用正式默认参数的内存覆盖，完成后恢复，不覆盖已保存的调参结果。

## 验证

- `npm run deck-scrub`：正式 200/1200 时钟与行为回归，保留普通横滑检查。
- `node lab/check-deck-pause.mjs`：旧 600/120 值、可调参数、接触快照和验证边界。
- 页面“响应／松手／边界／探索”验收使用真实组件监听链，仅替代合成事件不支持的指针捕获。原生 iPhone 事件、触感与 WKWebView 生命周期仍需实机确认。

title: 网页界面
summary: 从手机或另一台电脑访问整个网络

网络中的任意设备都可提供 Khor 网页界面。在手机或另一台电脑上打开，无需在访问设备上安装应用。

```sh
khor web
```

命令会输出链接与二维码。

## 运行位置

`khor serve` 默认在本地网络的 5467 端口提供界面。通过 `KHOR_WEB_PORT` 可修改端口；访问设备需要能连接主机的局域网地址。

该界面不使用 TLS，面向局域网使用。不要将端口直接暴露到公网。

使用 `khor faces` 可查看当前设备运行的界面及网页端口。

## 访问密钥

链接包含访问密钥，请避免将其放入同步文档。生成新密钥会让以前分享的链接全部失效：

```sh
khor web --new
```

## PIN 锁

为应用窗口和网页界面设置 PIN：

```sh
khor lock pin             # 从标准输入读取一行
khor lock on
khor lock timeout 5       # 分钟：0、1、5、15、60；0 表示永不锁定
```

此设置不会锁定命令行客户端。

## macOS 连接问题

macOS 防火墙首次可能阻止局域网传入连接，请在防火墙设置中允许 Khor。`khor web` 在输出链接前会检查地址是否可达；若不可达，会说明问题，避免给出无法使用的链接。

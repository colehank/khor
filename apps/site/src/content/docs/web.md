---
title: 网页脸
summary: 拿手机打开一个链接，就是整张网
order: 4
---

任一台入网的机器都能出一张网页。拿手机或者别的电脑打开，看到的是整张网，那台设备上什么都不用装。

```sh
khor web
```

它打印一个链接和二维码。

## 开在哪

网页由 `khor serve` 开在局域网上，默认端口 5467，用 `KHOR_WEB_PORT` 改。打开它的设备要够得着这台机器的局域网地址。

它没有 TLS，不是给公网的：不要把这个端口暴露出去。

`khor faces` 看本机开着哪几张界面、网页脸听的是哪个端口。

## 密钥

链接里带密钥，别贴进会同步的文档。换一把，之前发出去的链接全部作废：

```sh
khor web --new
```

## 打开密码

给 app 窗口和网页脸加一道 PIN：

```sh
khor lock pin             # 从标准输入读一行
khor lock on
khor lock timeout 5       # 分钟：0、1、5、15、60，0 是永不
```

它不锁命令行。

## macOS 上连不上

系统防火墙开着时，第一次会拦住 khor 接收局域网的连接，在系统设置的防火墙里放行它。`khor web` 会先探一次它要印的地址，探不通就不印链接，并说明原因。

Stay connected保持连接

Build a decentralized peer-to-peer network with Khor. Your devices stay connected as you move between wired, Wi-Fi, and cellular connections, with a relay keeping work moving while Khor finds a direct path.用 Khor 构建去中心化的点对点网络。切换有线网、无线网或蜂窝网时，设备依然保持连接；Khor 通过中继衔接，同时寻找直连路径。

Continue anywhere随时继续工作

Pick up the same session on a laptop or phone. Use Codex, Claude Code, or a terminal through Khor, with access to files and web apps on the target device and its Git history.在笔记本或手机上接着处理同一个会话。通过 Khor 使用 Codex、Claude Code 或终端，随时访问目标设备的文件与 Web 应用，甚至追踪 Git 日志。

Let Khor take over交给 Khor

Give Khor Agent a task from a laptop or phone. It coordinates devices and agents across the network and brings the result back to you.从笔记本或手机将任务交给 Khor Agent。它会协调网络中的设备与智能体，再把结果交回。
